# 拼图视觉仿真交付说明

## 直接运行打包程序

解压 `拼图视觉仿真_Linux_x86_64.zip`，进入解压后的目录，双击
`启动拼图仿真.sh`，或者在终端运行：

```bash
./启动拼图仿真.sh
```

也可以直接运行：

```bash
./拼图视觉仿真/拼图视觉仿真
```

## 系统要求

- 64 位 x86 Linux；
- 图形桌面环境；
- 不需要另外安装 Python、NumPy 或 OpenCV。

## 源码运行

若需要修改算法，可安装 `requirements.txt` 后运行：

```bash
python3 puzzle_gui.py
```

输出的矩阵采用图像像素坐标：x 向右、y 向下。
