# MaixCAM2 自动黑纸 ROI A/B 操作与调参手册

## 1. 交付版本

| 版本 | 应用目录 | 发布包 | 设备参数路径 | 识别坐标 |
|---|---|---|---|---|
| 稳定版 | `maixcam2_app/` | `maix-diansai_1-v1.0.0.zip` | `/root/maixcam2_puzzle/vision_settings.json` | 固定矩形ROI像素 |
| A 四边形掩膜与拼装规划 | `maixcam2_app_A_quad/` | `diansai_quad-v1.5.0.zip` | `/root/maixcam2_puzzle_A/vision_settings.json` | 原相机像素 + 横竖A4毫米 |
| B 透视展开 | `maixcam2_app_B_warp/` | `diansai_warp-v1.1.0.zip` | `/root/maixcam2_puzzle_B/vision_settings.json` | 420×460工作像素 + 机械区毫米 |

> A版必须部署 `v1.5.0`。该版本包含横竖AUTO、PAPER V/H手动兜底、设置V5和KNOWN 32点稳健匹配。

稳定版未被A/B实现修改。现场对比时一次只安装或运行一个新版本，A/B参数互不覆盖。

## 2. 程序识别区域

完整黑色A4纸竖放为210×297mm、横放为297×210mm。A版AUTO判断方向，也可在PAPER项手动切换：竖放默认中间210×230mm，横放默认中间230×210mm；黄色机械区域仍可在屏幕上移动和缩放。

```text
上端舍弃 33.5mm
机械有效区 230mm
下端舍弃 33.5mm
```

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `X` | 0.0mm | 黄色区域左边的A4毫米坐标 |
| `Y` | 33.5mm | 黄色区域上边的A4毫米坐标 |
| `W` | 210.0mm | 黄色区域宽度，最大210mm |
| `H` | 230.0mm | 黄色区域高度，最大230mm |
| `SPLIT` | 148.5mm | 上下区红线的A4毫米Y坐标 |

五个值均以0.5mm步进调整。区域必须完整位于A4内，红线必须位于黄色区域内部。蓝框到毫米坐标使用完整四角单应矩阵，不使用统一毫米/像素比例。

## 3. 第一次自动锁定

相机和黑纸固定后执行一次，正常识别不会逐帧重新找纸：

1. 把1～4片白色碎片放在黑纸内，碎片互不接触，也不能接触黑纸外边缘。
2. 点击正常界面的 `CAL`。
3. 保持在 `ROI` 页，点击 `AUTO ROI`。
4. 成功时屏幕显示 `AUTO ROI OK xx%`，并画出青色完整A4和黄色机械有效区。
5. 点击中间值按钮按 `X/Y/W/H/SPLIT/PAPER` 循环；机械值每次调整0.5mm，PAPER用`-`或`+`切换V/H。
6. 黄色有效区完整避开纸边、固定支架和不希望进入机械区域的位置后，点击 `LOCK ROI`。
7. 显示 `ROI LOCKED` 后，纸张四角、机械区域和分界线已写入本版本独立参数文件。
8. 再次点击顶部 `CAL` 返回正常识别。

`AUTO ROI`只在点击时处理当前一帧。相机和黑纸固定后不需要反复点击。

## 4. AUTO ROI 失败

显示 `AUTO ROI FAIL` 时：

- 当前工作副本不会变成空值；
- 上次已保存ROI不会被覆盖；
- 可以调整光照、移开接触纸边的碎片后再次点击；
- 不需要删除参数文件，也不需要重启程序。

优先检查：完整A4四条外边缘是否可见、白片是否伸出纸边、亮地面与黑纸对比是否足够、暗色杆件是否与黑纸连成一个轮廓。

## 5. CAL 顶部页面

| 页面 | 画面内容 | 判断标准 |
|---|---|---|
| `ROI` | 原相机画面、蓝色完整A4、黄色机械区域、红色分界线 | 蓝框沿黑纸外边，黄框位于机械可达区域，红线与实物分区一致 |
| `MASK` | 算法实际使用的二值图 | 碎片独立为白色，有效区外为黑色 |
| `RESULT` | 轮廓分类 | 目标为绿色，无不需要的橙/红/紫轮廓 |
| `ADV` | 结果预览与当前高级参数 | 一次只调一项，观察状态变化 |
| `CAL` | 返回正常识别界面 | 不改变KNOWN/UNKNOWN模式 |

轮廓颜色：绿色为完整有效、橙色为触边、红色为过小、紫色为过大。

## 6. CAL 底部按钮

ROI、MASK、RESULT页从左到右：

| 按钮 | 作用 |
|---|---|
| `AUTO ROI` | 对当前原相机帧执行一次黑纸定位 |
| `-` | 当前X/Y/W/H/SPLIT减小0.5mm；PAPER项切换V/H |
| 当前参数和值 | 点击后循环选择 `X/Y/W/H/SPLIT/PAPER` |
| `+` | 当前X/Y/W/H/SPLIT增大0.5mm；PAPER项切换V/H |
| `LOCK ROI` | 人工确认并保存纸张四角、机械区域与分界线 |

ADV页从左到右：

| 按钮 | 作用 |
|---|---|
| `PARAM:<名称>` | 循环选择 `TH/MIN/OPEN/CLOSE` |
| `-` | 减小当前参数 |
| 当前值 | TH时点击可在AUTO和固定阈值间切换 |
| `+` | 增大当前参数 |
| `SAVE` | 只保存分割参数，必须达到 `GOOD 4/4` |

## 7. 两种保存门

| 保存动作 | 允许条件 | 保存内容 |
|---|---|---|
| `LOCK ROI` | 有合法纸张四角；当前有1～4片完整碎片；无EDGE和过大轮廓 | `paper_quad`、`PAPER`、`X/Y/W/H/SPLIT` |
| ADV `SAVE` | `GOOD 4/4` | `TH`、`MIN`、`OPEN`、`CLOSE` |

两类保存互不覆盖。黑纸上只有1片时可以锁定ROI，但不能保存高级分割参数。

## 8. 如何判断参数调对

状态栏分两行。第一行显示ROI或保存状态，第二行显示：

```text
N 4/4 | EDGE 0 | SMALL 0 | LARGE 0
```

| 状态 | 含义 | 处理顺序 |
|---|---|---|
| `GOOD 4/4` | 恰好四片完整碎片 | 可以ADV保存 |
| `MISS` | 碎片漏检或顶点数异常 | 先看MASK，再调TH或减小MIN/OPEN |
| `NOISE` | 有额外有效轮廓 | 提高MIN或OPEN，检查反光和纸屑 |
| `EDGE` | 碎片接触有效区边缘 | 调整X/Y/W/H扩大对应边或把碎片移入黄框 |
| `BACKGROUND` | 背景成为过大亮轮廓 | 检查自动四角、TH和现场曝光 |

正确画面的必要条件：实际四片都在黄框内；MASK中只有四块独立白区；RESULT中四片均绿色；第二行各异常计数为0。

## 9. ADV 参数调整顺序

| 参数 | 步进/范围 | 调大效果 | 风险 |
|---|---|---|---|
| `TH` | AUTO或固定值，每次5灰度 | 只保留更亮白片 | 过高会漏掉偏暗贴片 |
| `MIN` | 每次0.0005面积比例 | 过滤小噪点 | 过大会漏掉远距离小碎片 |
| `OPEN` | 1/3/5/7 | 去除小白点 | 过大会侵蚀碎片 |
| `CLOSE` | 1/3/5/7/9 | 填补白片内部黑孔 | 过大会连接相邻碎片 |

现场推荐顺序：先AUTO ROI并核对PAPER V/H，再调X/Y/W/H/SPLIT；然后保持 `TH=AUTO` 看MASK。仍有问题时先调TH，再调MIN，最后才调OPEN/CLOSE。每次只改一项，并同时观察MASK、RESULT和异常计数。

## 10. A版拼装规划

正常界面只使用完整且位于红线上方的碎片。A版v1.8.0选择模式或材料后保持完全待机，点击`START`才开始检测；连续3帧毫米顶点位置稳定后求解一次并缓存，状态依次显示 `STABLE 1/3`、`STABLE 2/3` 和 `PLAN OK N=<数量>`。机构开始移动后画面变化不会重复搜索；再次点击START、切换模式/材料、进入CAL、重存已知布局或修改机械参数会清缓存。

| 模式 | 使用方法 | 目标输出 |
|---|---|---|
| `KNOWN` | 赛前先保存一次正确四片布局，运行时匹配K1～K4 | 固定100×60mm矩形和每片目标位姿 |
| `UNKNOWN` | 不需要模板，1～4片稳定后自动回溯 | 90×50mm～120×90mm范围内的矩形 |

KNOWN布局保存步骤：把四片在红线下方拼成正确100×60mm关系，相邻片保留约1～2mm黑缝，避免同色白片成为一个连通轮廓；依次点击`KNOWN → START → SAVE`，看到`KNOWN SAVED PLAN OK`。布局保存到 `/root/maixcam2_puzzle_A/known_templates.json`，不会依赖MaixVision的`/tmp`运行目录。随机放回上半区后再次点击START，程序最多比较24种一对一分配。

UNKNOWN使用等长边反向拼接、重叠与缝隙栅格校验。白片按几何评分；扑克牌片在几何正确候选之间增加接缝颜色和梯度连续性评分。状态 `PLAN NO_ASSEMBLY` 或 `PLAN SEARCH_LIMIT` 表示本次没有安全目标，程序不会输出越界坐标。

规划画面含义：红线为上下分界；紫色为最终目标矩形；彩色细线为各片目标轮廓；橙色箭头从当前中心指向目标中心；文字显示编号、目标A4毫米坐标和旋转增量。

## 11. A版与B版区别

| 指标 | A 四边形掩膜 | B 透视展开 |
|---|---|---|
| 正常画面 | 原640×480相机图 | 拉正后的420×460工作区居中显示 |
| 背景隔离 | 四边形外强制清零 | 展开后固定平面掩膜 |
| 轮廓像素坐标 | 原相机坐标 | 工作区坐标 |
| 毫米中心 | 当前方向完整A4左上原点，并支持拼装目标 | 210×230机械区左上原点 |
| 透视影响 | 仍存在 | 已校正 |
| 计算量 | 较低 | 较高，需实机测帧率 |

先用A版验证现场自动四角和识别稳定性，再用完全相同摆放、光照、相机位置运行B版。最终依据中心抖动、顶点稳定性、误检和帧率选择，不在PC合成图阶段预设胜者。

## 12. PC同帧对比

自动识别四角：

```powershell
python tools\compare_roi_variants.py --image "原始帧.jpg" --output-dir "tmp\ab_compare" --inset-mm 2
```

显式提供四角：

```powershell
python tools\compare_roi_variants.py --image "原始帧.jpg" --output-dir "tmp\ab_compare" --quad x1 y1 x2 y2 x3 y3 x4 y4 --inset-mm 2
```

输出 `<名称>_A_quad.jpg`、`<名称>_B_warp.jpg` 和 `<名称>_AB.jpg`。必须使用无界面叠加的原始相机帧。

## 13. 安装与运行

A版发布包：

```text
maixcam2_app_A_quad/dist/diansai_quad-v1.5.0.zip
```

B版发布包：

```text
maixcam2_app_B_warp/dist/diansai_warp-v1.1.0.zip
```

ZIP内文件直接位于根目录，兼容MaixVision `/tmp/maixpy_run` 平铺运行。不要只上传 `main.py`；必须使用完整ZIP或完整应用目录。

## 14. 实机验收清单

| 项目 | 通过标准 |
|---|---|
| AUTO ROI | 1～4片不同摆放下找到同一组A4四角 |
| 失败回退 | 遮挡纸边后显示FAIL，旧ROI仍可用 |
| 触摸 | 五个顶部和五个底部区域无误触 |
| 重启恢复 | LOCK和ADV保存后重启恢复各自参数 |
| 识别 | 1～4片数量与实际一致，无纸外背景轮廓 |
| 坐标 | 静止碎片中心抖动满足后续电机要求 |
| 帧率 | A/B分别记录现场平均帧率 |
| 龙门架 | 机构不接触纸边时定位可用；动态遮挡仍不属于本版目标 |
| 稳定门 | 静止三帧后只求解一次，移动碎片时目标不跳变 |
| 已知规划 | 随机位置和角度下K1～K4目标仍为正确100×60mm布局 |
| 未知规划 | 现场白片与扑克牌片分别记录成功率、节点数和求解时间 |
| 机械坐标 | 目标中心和旋转增量与龙门架坐标转换逐片核对 |

PC自动测试不能替代以上实机验收。
