# MaixCAM2 A版自动拼装修复设计

## 1. 问题与目标

当前画面中的 `N=4` 只证明视觉层识别到四个完整轮廓，并不表示规划成功。两个现场问题来自规划层：

| 模式 | 当前行为 | 修复后的行为 |
|---|---|---|
| KNOWN | `SAVE` 要求四片已经在下半区手工拼好，否则模板为空并显示 `KNOWN_NEEDS_FOUR` | 四片随机放在上半区，点击 `SAVE` 后自动求解100×60mm布局、保存K1～K4，并立即显示目标 |
| UNKNOWN | 所有候选共用一个笼统的 `NO_ASSEMBLY`，失败后不绘制目标 | 自动求解允许现场轮廓误差，并显示最主要的拒绝原因；成功时立即绘制下半区目标 |

题目原文只规定现场碎片数量不大于4、每片不大于5边、每边不短于20mm、每片至少一边属于目标外框，并没有保证任意相邻碎片必须由两条完整等长边一一对应。因此求解器必须支持一条边与多段共线边形成接缝。

## 2. 总体方案

KNOWN和UNKNOWN共用同一个未知几何求解核心。UNKNOWN直接返回当前拼法；KNOWN的 `SAVE` 在成功求解后，把求解得到的目标轮廓规范到精确100×60mm目标框，再生成并原子保存K1～K4模板。这样KNOWN首次登记和UNKNOWN现场求解使用同一套几何逻辑，避免两种模式出现相反的摆放要求。

求解仍只接收 `complete=True` 且 `region=upper` 的碎片。红线下方、跨线或触碰黄色边界的轮廓不参与规划，防止给电机输出不安全目标。

## 3. UNKNOWN求解改进

求解分为两级：

1. 优先执行现有的整边匹配快速搜索。
2. 快速搜索无解时，执行分段接缝搜索：允许源边的一个端点对齐目标边端点，并允许另一端落在目标边内部；后续碎片可以补齐剩余共线段。

边长误差由固定 `max(2.5mm, 4%)` 改为结合相机测量误差的容差，但不改变实体比例、不允许镜像。完整布局验收继续检查目标尺寸、重叠和填充率；验收会记录各阶段拒绝计数，并把主导失败原因放进 `AssemblyPlan.reason`。

失败原因包括：

| 状态 | 含义 |
|---|---|
| `EDGE_MISMATCH` | 没有形成足够的整边或分段接缝候选 |
| `SIZE_REJECT` | 候选外框不在题目矩形尺寸范围内 |
| `FILL_REJECT` | 外框内缺口过大，不能视为矩形 |
| `OVERLAP_REJECT` | 拼放后碎片实体重叠 |
| `SEARCH_LIMIT` | 搜索达到节点上限 |

为了防止纯粹放宽阈值产生错误目标，尺寸、填充和重叠仍是最终硬验收条件。参数只放宽到覆盖固定相机远距离识别的毫米误差，不使用题目允许的20mm装配评分误差作为视觉容差。

## 4. KNOWN保存流程

点击KNOWN页 `SAVE` 后执行以下流程：

1. 筛选四片完整且位于上半区的碎片。
2. 使用改进后的几何求解器求出矩形拼法。
3. 校验求解结果可映射到100×60mm且不发生非均匀严重变形。
4. 按形状描述子稳定生成K1～K4，并保存求解后的局部目标轮廓。
5. 重新用当前四片和新模板生成KNOWN规划，使本帧或下一帧立即出现下半区目标。

保存失败时不覆盖旧模板。状态栏保留具体原因，例如 `SAVE EDGE_MISMATCH`，不会再被同一帧的 `PLAN KNOWN_NEEDS_FOUR` 覆盖。

## 5. 显示与状态优先级

触摸动作产生的 `SAVE ...` 状态至少保留一个短周期，规划状态不能在同一帧覆盖它。正常规划时显示：

- 稳定累计：`STABLE 1/3`
- 规划成功：`PLAN OK N=4`
- 规划失败：`PLAN SIZE_REJECT` 等具体原因
- KNOWN登记成功：`KNOWN SAVED PLAN OK`

只有 `plan.success=True` 才绘制机械目标；失败时仍显示红色分界线和诊断文本，不生成可能错误的电机坐标。

## 6. 测试与验收

PC测试覆盖图2四片、随机旋转平移、带测量噪声、长边对多段短边、无解、重叠、尺寸越界、KNOWN上半区保存和状态不被覆盖。回归测试还必须覆盖平铺导入、全量pytest和compileall。MaixCAM2实机验收以 `N=4 -> STABLE 3/3 -> PLAN OK N=4`、下半区出现四片彩色目标轮廓为通过标准。
