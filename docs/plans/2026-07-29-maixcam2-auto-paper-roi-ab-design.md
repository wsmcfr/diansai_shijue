# MaixCAM2 自动黑纸 ROI A/B 双版本设计

## 1. 目标

在保留当前稳定工程的前提下，复制出两个相互独立的 MaixCAM2 应用，对比以下两种固定工作区方案：

| 版本 | 核心方法 | 主要目的 |
|---|---|---|
| A | 四边形掩膜 | 保持原相机坐标，以较小改动彻底屏蔽黑纸外亮背景 |
| B | 透视展开 | 把有效工作区拉正为固定物理比例，直接输出稳定像素及毫米坐标 |

共同目标：

- 点击一次 `AUTO ROI` 自动识别完整黑色 A4 纸并生成机械有效区；
- 相机和黑纸固定后锁定结果，正常识别不再逐帧寻找黑纸；
- 黑纸上允许已有 1～4 片白色碎片，但碎片不得接触黑纸外边缘；
- 自动定位失败时显示 `AUTO ROI FAIL`，不覆盖工作副本和已保存结果；
- 默认界面保持简洁，需要时通过 `ADV` 调整详细分割参数；
- 两个版本分别保存参数、分别打包，便于使用同一现场画面进行对比。

## 2. 非目标

- 不修改当前稳定工程 `maixcam2_app`；
- 不在本轮处理龙门架动态遮挡；
- 不实现拼图求解与电机控制；
- 不要求方案 A 消除透视形变；
- 不把黑纸定位改成逐帧跟踪；
- 不使用当前 MaixVision 截图替代原始相机帧进行最终实机验收。

## 3. 工程隔离

| 路径 | 内容 | 修改策略 |
|---|---|---|
| `maixcam2_app/` | 当前稳定基线 | 保持不变 |
| `maixcam2_app_A_quad/` | 方案 A：四边形掩膜 | 从稳定版复制后独立修改 |
| `maixcam2_app_B_warp/` | 方案 B：透视展开 | 从稳定版复制后独立修改 |

两个新工程必须使用不同应用 ID、不同发布 ZIP 名称和不同设备参数目录：

```text
/root/maixcam2_puzzle_A/vision_settings.json
/root/maixcam2_puzzle_B/vision_settings.json
```

已知模板文件也保留在各自工程目录中，禁止两个版本互相覆盖。

## 4. 共用黑纸定位模型

### 4.1 定位输出

黑纸定位模块输出一个独立结果对象，至少包含：

| 字段 | 含义 |
|---|---|
| `paper_quad` | 完整 A4 黑纸在原图中的四个有序角点 |
| `active_quad` | 机械有效区在原图中的四个角点 |
| `confidence` | 0～1 的候选置信度 |
| `threshold` | 本次暗色分割使用的阈值 |
| `reason` | 成功说明或失败原因 |

四个角点顺序必须稳定，使物理 A4 坐标可以映射到原相机画面。定位失败返回明确失败结果，不返回半有效四边形。

### 4.2 候选生成与评分

点击 `AUTO ROI` 时才执行以下流程：

1. 将整帧转换为灰度或亮度通道；
2. 生成暗色前景掩膜；
3. 使用闭运算连接黑纸区域，白色碎片作为内部孔洞保留，不影响纸张外边界；
4. 提取外轮廓并计算凸包；
5. 拟合四边形候选；
6. 按面积、凸性、矩形度、四角质量和 A4 长宽比进行评分；
7. 选择最高分候选；
8. 置信度未达到门槛时返回 `AUTO ROI FAIL`。

长杆、笔和龙门架等暗色物体可能形成候选，但其长宽比、矩形度或面积得分必须低于 A4 候选。

## 5. 物理有效区

完整 A4 使用标准物理坐标：

```text
宽：0～210mm
长：0～297mm
```

龙门架只能覆盖中间约 210×230mm，因此基础有效区固定为：

```text
x = 0～210mm
y = 33.5～263.5mm
```

用户通过一个整体 `INSET` 值继续向内缩进。`INSET` 使用毫米而不是相机像素，例如 `INSET=2mm` 时：

```text
x = 2～208mm
y = 35.5～261.5mm
```

该物理矩形通过完整 A4 的四角映射为原图 `active_quad`。这样方案 A 与方案 B 使用完全相同的机械有效范围。

## 6. 方案 A：四边形掩膜

### 6.1 数据流

```text
原始 640×480 帧
  -> 取 active_quad 的轴对齐外接矩形
  -> 灰度、阈值、开闭运算
  -> 将 active_quad 外部像素强制清零
  -> 提取白色碎片轮廓
  -> 按 active_quad 真实面积进行面积过滤
  -> 按轮廓到四边形边缘的距离判断是否完整
  -> 输出原相机像素坐标
```

### 6.2 行为要求

- 四边形外亮地面不得进入白色占比和轮廓统计；
- 轮廓坐标、中心、顶点和绘制继续使用原图坐标；
- 边界判断从轴对齐矩形切换为四边形边界；
- 形状描述仍受相机透视影响；
- 可通过 A4 映射矩阵额外计算毫米中心，但正常叠加仍显示在原图上。

## 7. 方案 B：透视展开

### 7.1 标准展开尺寸

完整 A4 使用 2 像素/mm 展开：

```text
完整 A4：420×594 像素
机械有效区：420×460 像素
```

### 7.2 数据流

```text
原始 640×480 帧
  -> 使用 paper_quad 计算单应性矩阵
  -> 展开为 420×594 的标准 A4 图像
  -> 裁取 y=67～527 的 420×460 工作区
  -> 按 INSET 生成固定物理边界掩膜
  -> 阈值、开闭运算和轮廓识别
  -> 输出工作区像素坐标
  -> 按 2 像素/mm 换算毫米坐标
```

### 7.3 行为要求

- 正常识别界面直接显示拉正后的 420×460 工作区；
- 显示时保持 210:230 比例，不拉伸为 640:480；
- 碎片形状、角度和模板描述子在展开图上计算；
- 每个碎片同时输出工作区像素中心和毫米中心；
- 保存原相机四角与单应性输入，必要时可把结果反算回原图；
- 单应性矩阵无效时显示 `WARP ERROR`，继续使用上次锁定结果。

## 8. 调参界面

### 8.1 顶部页面

两个版本使用相同顶部按钮：

```text
ROI | MASK | RESULT | ADV | CAL
```

| 页面 | 内容 |
|---|---|
| `ROI` | 原图、完整 A4 青色轮廓、机械有效区黄色轮廓和定位置信度 |
| `MASK` | 只显示有效区内部二值结果，有效区外固定为黑色 |
| `RESULT` | 绿色有效、橙色触边、红色过小、紫色过大 |
| `ADV` | `TH/MIN/OPEN/CLOSE` 的分段选择和加减控制 |
| `CAL` | 返回正常识别界面，不改变 KNOWN/UNKNOWN 模式 |

### 8.2 默认引导控制

默认页底部只保留五个大按钮：

```text
AUTO ROI | - | INSET:2mm | + | LOCK ROI
```

`AUTO ROI` 成功后只更新 CAL 工作副本。只有点击 `LOCK ROI` 才持久保存纸张四角、INSET 和机械有效区。

### 8.3 高级参数

`ADV` 页面显示 `TH/MIN/OPEN/CLOSE` 四个分段选项，底部提供减、当前值、加、步长和保存。

保存门分离：

| 动作 | 条件 | 保存内容 |
|---|---|---|
| `LOCK ROI` | 黑纸定位置信度合格 | 纸张四角、INSET、机械有效区；允许当前只有 1～4 片 |
| ADV `SAVE` | `GOOD 4/4` | TH、MIN、OPEN、CLOSE 等分割参数 |

### 8.4 状态显示

状态栏改为两行大字，避免当前单行指标过密：

```text
ROI READY  CONF 92%
N 4/4 | EDGE 0 | SMALL 0 | LARGE 0
```

必要时第二行轮换或精简显示 `TH` 与 `WHITE`，文字不得覆盖按钮或画面关键区域。

## 9. 持久化与兼容回退

新版本现场设置至少包含：

- `paper_quad`；
- `inset_mm`；
- 兼容矩形 `roi`；
- `fixed_threshold`；
- `min_area_ratio`；
- `open_kernel`；
- `close_kernel`；
- 设置版本号。

`active_quad`由 `paper_quad`、A4物理尺寸、机械裁剪量和 `inset_mm`重新计算，避免保存重复状态。

错误处理：

| 错误 | 行为 |
|---|---|
| `AUTO ROI FAIL` | 不覆盖工作副本，不覆盖已保存结果，允许重试 |
| 未点击 `LOCK ROI` 退出 | 丢弃新四角和新 INSET |
| 设置文件损坏 | 显示 `SETTINGS ERROR`，使用兼容矩形 ROI 回退 |
| A 版四边形无效 | 显示 `ROI ERROR`，保留上次结果 |
| B 版单应性无效 | 显示 `WARP ERROR`，保留上次结果 |
| 保存失败 | 显示错误类型，继续运行，不删除旧文件 |

## 10. 测试设计

| 测试层级 | 验证内容 |
|---|---|
| 黑纸定位 | 透视、旋转、亮地面、暗色杆件、1～4 片白色孔洞下仍选择 A4 |
| 错误拒绝 | 无 A4、比例错误、边界不完整、低置信度时失败且不覆盖旧值 |
| 物理区域 | 上下各裁 33.5mm、INSET 毫米换算和角点顺序正确 |
| A 版 | 四边形外清零、真实面积过滤、四边形边界判断和原图坐标正确 |
| B 版 | 420×594 展开、420×460 裁剪、2 像素/mm 和毫米坐标正确 |
| UI | 顶部按钮不重叠、状态两行可读、两类保存门独立 |
| 持久化 | A/B 路径独立、损坏回退、未锁定退出不污染旧值 |
| 部署 | 两个 app.yaml、两个 ZIP 和 MaixVision 平铺导入均包含全部模块 |

所有新行为先写失败测试，再进行最小实现。当前稳定版测试必须继续通过。

## 11. 实机 A/B 对比

使用相同黑纸、相同碎片、相同相机位置和相同光照分别运行 A、B，记录：

| 指标 | 观察重点 |
|---|---|
| 自动 ROI 成功率 | 不同 1～4 片摆放下能否稳定找到同一组 A4 四角 |
| 识别数量 | 是否持续得到正确碎片数 |
| 中心抖动 | 静止碎片连续帧中心变化 |
| 顶点稳定性 | 远距离和旋转时 3～5 边拟合是否稳定 |
| 背景误检 | 是否仍出现 `BACKGROUND` 或纸外轮廓 |
| 帧率 | B 版透视变换增加的处理耗时 |
| 坐标实用性 | A 原图坐标与 B 毫米坐标对后续电机控制的适用性 |

最终依据实机数据选择正式版本，不在 PC 合成测试阶段预设胜者。

## 12. 已知限制

- 当前只有 MaixVision 界面截图，没有无叠加的 640×480 原始帧；
- PC 合成图可以验证算法边界，但不能证明现场黑纸定位成功；
- 黑纸外边缘被碎片或机构大面积遮挡时，自动定位允许失败并保留旧结果；
- 龙门架动态遮挡和最终电机坐标标定仍属于后续工作。
