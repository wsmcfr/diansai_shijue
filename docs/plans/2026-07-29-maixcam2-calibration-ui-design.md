# MaixCAM2 固定 ROI 与屏幕调参界面设计

## 1. 目标

在现有拼图识别程序中增加一个 `CAL` 切换按钮和一个屏幕调参界面，使固定安装的 MaixCAM2 可以在现场完成 ROI、阈值、最小面积和形态学参数校准，并通过二值图、分类轮廓和质量状态直接判断参数是否合适。

## 2. 已确认条件

| 项目 | 结论 |
|---|---|
| 摄像头位置 | 固定 |
| 黑色 A4 位置 | 固定 |
| 机械有效区域 | 230mm × 230mm |
| A4 长边舍弃 | 共约 67mm，上下各约 33mm |
| 调参入口 | 使用一个 `CAL` 切换按钮 |
| 切换行为 | 第一次按下进入调参界面，再次按下返回正常界面 |
| 校准目标 | 调试时摆放四片互不接触、互不重叠的白色碎片 |

## 3. 现象与根因

近距离时黑色纸面基本充满相机画面，程序可以检测到碎片。扩大到整张 A4 后，亮色地面进入当前整帧 ROI，状态栏从约 `TH=138` 变化到约 `TH=119`，检测结果变为 `N=0`。

当前算法使用 `cv2.RETR_EXTERNAL` 提取最外层轮廓。亮地面在二值图中形成包围黑色 A4 的大面积白色外轮廓，A4 内的白色碎片位于该轮廓层级内部；外层亮背景又因超过 `max_area_ratio=0.60` 被过滤，最终没有可用碎片。

已经使用同结构合成画面验证：

| 工作区 | 当前算法识别数量 |
|---|---:|
| 整幅 640×480 | 0 |
| 仅黑纸内部 ROI | 4 |

因此固定 ROI 是必要修复，阈值调节只能作为 ROI 正确后的第二层调节手段。

## 4. 方案选择

| 方案 | 结论 |
|---|---|
| 仅增加阈值加减 | 不采用，无法排除亮地面外轮廓 |
| 固定 ROI + 屏幕调参 | 采用，适合相机和 A4 均固定的条件 |
| 每次自动寻找 A4 | 不采用，容易被龙门架、阴影和其他黑色结构干扰 |

## 5. 状态模型

程序保留两个相互独立的状态：

| 状态 | 可选值 | 作用 |
|---|---|---|
| 识别模式 | `KNOWN` / `UNKNOWN` | 决定已知模板匹配或未知编号 |
| 界面模式 | `RUN` / `CAL` | 决定显示正常识别界面或调参界面 |

切换规则：

1. 程序启动时进入 `UNKNOWN + RUN`。
2. 正常界面的 `CAL` 按钮为灰色。
3. 第一次点击 `CAL` 后进入调参界面，`CAL` 按钮变绿色。
4. 调参界面继续实时取图和运行视觉算法，不冻结画面。
5. 再次点击同一个 `CAL` 按钮后返回正常界面。
6. 进入或退出 `CAL` 不改变当前 `KNOWN/UNKNOWN` 模式。
7. 未点击调参界面的参数保存按钮时，退出 `CAL` 将恢复进入调参前的已保存参数。

## 6. 正常界面

正常界面顶部按钮调整为：

```text
[ KNOWN ] [ UNKNOWN ] [ SAVE ] [ CAL ]
```

`KNOWN`、`UNKNOWN` 和 `SAVE` 行为保持不变。新增 `CAL` 使用与现有按钮相同的松开触发方式，避免长按重复切换。

## 7. 调参界面布局

调参界面按 640×480 坐标设计，固定各区域高度，避免状态文字变化导致按钮移动。

```text
+----------------------------------------------------------------+
| [ ROI ] [ MASK ] [ RESULT ]                         [ CAL ]     |
+----------------------------------------------------------------+
|                                                                |
|                    实时预览区域                                 |
|                                                                |
|       ROI边框 / 二值掩膜 / 分类轮廓结果                         |
|                                                                |
+----------------------------------------------------------------+
| GOOD 4/4  EDGE=0  SMALL=2  LARGE=0  TH=134  WHITE=8.2%        |
+----------------------------------------------------------------+
| [ ITEM:TH ] [  -  ] [ AUTO ] [  +  ] [ STEP:5 ] [ SAVE ]     |
+----------------------------------------------------------------+
```

| 区域 | 高度 | 作用 |
|---|---:|---|
| 顶部页签 | 48px | 切换 ROI、MASK、RESULT；右侧保留 CAL 退出按钮 |
| 实时预览 | 316px | 显示相机、二值图或轮廓分类结果 |
| 诊断状态 | 40px | 显示质量、数量、阈值和白色占比 |
| 参数控制 | 76px | 选择参数、减小、模式/数值、增大、步长和保存 |

## 8. 三个预览页面

### 8.1 ROI 页面

ROI 页面显示原始相机画面和固定矩形工作区。矩形内部为有效识别区域，外部加半透明暗化效果，使亮色地面是否被排除一眼可见。

`ITEM` 在 `LEFT`、`RIGHT`、`TOP`、`BOTTOM` 四条边之间循环。当前选中边显示黄色，其他边显示青色。`-` 和 `+` 按当前步长移动选中边。

ROI 必须满足：

- 完整位于 640×480 图像内部；
- 宽高均不小于安全最小值；
- 矩形内部全部落在黑色 A4 的中部有效区域；
- 不包含亮色地面、手、龙门架和屏幕按钮区域。

### 8.2 MASK 页面

MASK 页面把 ROI 内的二值掩膜放大显示，并把 ROI 外部保持为深灰色。

正确画面应满足：

- 黑色 A4 显示为连续黑色；
- 四片白色碎片显示为四块连续白色区域；
- 白片内部没有明显黑孔；
- 不存在大量白色散点；
- 白色区域之间没有粘连。

`ITEM` 在 `TH`、`MIN`、`OPEN`、`CLOSE` 之间循环。

### 8.3 RESULT 页面

RESULT 页面显示分类后的全部候选轮廓，而不是只显示最终四片：

| 颜色 | 类别 | 含义 |
|---|---|---|
| 绿色 | `VALID` | 面积有效且不接触 ROI 边界 |
| 橙色 | `EDGE` | 接触 ROI 边界 |
| 红色 | `SMALL` | 面积低于最小面积阈值 |
| 紫色 | `LARGE` | 面积超过最大面积阈值 |

这样用户能够判断漏检发生在阈值分割、面积过滤还是 ROI 边界，而不是只看到 `N=0`。

## 9. 可调参数

| 参数 | 取值与操作 | 现场作用 |
|---|---|---|
| `LEFT/RIGHT/TOP/BOTTOM` | 1、5、10px步长 | 固定黑纸有效 ROI |
| `TH` | `AUTO` 或 0～255 | 自动 Otsu 或固定灰度阈值 |
| `MIN` | ROI 面积比例 | 允许远距离小碎片进入识别 |
| `OPEN` | 正奇数 1、3、5、7 | 去除小白色噪点 |
| `CLOSE` | 正奇数 1、3、5、7、9 | 填补白片内部小黑孔 |
| `STEP` | 1、5、10 | 控制单次按键调节幅度 |

当 `TH=AUTO` 时，中间按钮显示本帧 Otsu 实际阈值，例如 `AUTO:134`。用户切换到固定阈值后，`-` 和 `+` 才修改阈值。

## 10. 参数质量判断

调参时要求放置四片互不接触且完全位于 ROI 内的碎片。

| 状态 | 判定 | 用户动作 |
|---|---|---|
| `GOOD 4/4` | 恰好四个完整有效轮廓，无过大背景轮廓 | 可以保存 |
| `MISS n/4` | 有效完整轮廓少于四个 | 查看MASK，再检查ROI、TH和MIN |
| `NOISE` | 面积过滤前后仍有多余小轮廓 | 调整MIN或OPEN |
| `EDGE` | 任意候选轮廓接触ROI边界 | 扩大ROI或移动碎片 |
| `BACKGROUND` | 存在过大亮轮廓或白色占比异常 | 缩小ROI，排除亮地面 |

诊断状态同时显示：

- 完整有效轮廓数；
- 边缘轮廓数；
- 过小轮廓数；
- 过大轮廓数；
- 当前阈值；
- ROI 内白色像素比例。

`SAVE` 仅在 `GOOD 4/4` 时启用，防止把明显错误参数保存为现场配置。

## 11. 参数保存与恢复

运行参数独立保存为 JSON，内容至少包括：

```json
{
  "version": 1,
  "roi": [160, 30, 300, 420],
  "fixed_threshold": null,
  "min_area_ratio": 0.002,
  "open_kernel": 3,
  "close_kernel": 5
}
```

保存流程使用临时文件和原子替换，避免断电产生半个配置文件。

启动规则：

1. 优先加载已保存现场参数；
2. 文件不存在时使用 `config.py` 默认值和整帧 ROI；
3. 文件损坏时继续使用默认值，并在状态栏显示设置错误；
4. 进入 CAL 时复制一份工作参数；
5. 保存成功后才替换当前运行参数；
6. 未保存退出时丢弃工作参数，恢复进入 CAL 前的配置。

MaixVision 目前从 `/tmp/maixpy_run` 运行，正式实现需要把现场参数写入设备持久目录，不能依赖临时运行目录。

## 12. 视觉核心诊断扩展

现有 `DetectionResult` 增加只读诊断信息：

| 字段 | 内容 |
|---|---|
| `small_contours` | 面积过小轮廓 |
| `large_contours` | 面积过大轮廓 |
| `edge_contours` | 接触 ROI 边界轮廓 |
| `candidate_count` | 面积筛选前候选数量 |
| `white_ratio` | ROI 二值图白色像素比例 |

正常识别结果仍最多保留四片，调参界面使用完整诊断集合判断噪声与背景问题。

## 13. 错误处理

| 异常 | 行为 |
|---|---|
| ROI 越界或宽高过小 | 拒绝该次调节并显示 `ROI LIMIT` |
| 参数文件损坏 | 使用默认值并显示 `SETTINGS ERROR` |
| 保存失败 | 保持旧参数并显示 `SAVE ERROR` |
| 单帧视觉异常 | 显示 `VISION ERROR`，下一帧继续 |
| 调参期间退出应用 | 不保存未确认参数 |

## 14. 测试范围

### PC 自动测试

1. 亮色外部背景下整帧 ROI 识别为零、固定黑纸 ROI 识别四片的回归测试；
2. ROI 边界校验和步长调节测试；
3. `CAL` 单按钮往返切换且保留 KNOWN/UNKNOWN 模式测试；
4. AUTO/固定阈值切换测试；
5. SMALL、LARGE、EDGE 和白色占比诊断测试；
6. GOOD/MISS/NOISE/EDGE/BACKGROUND 状态判断测试；
7. 参数 JSON 保存、加载、损坏回退和未保存退出测试；
8. 原有全部测试回归。

### MaixCAM2 实机测试

1. 第一次点击 CAL 进入调参，第二次点击返回正常界面；
2. ROI 页面排除全部亮色地面；
3. MASK 页面显示四个独立白色区域；
4. RESULT 页面颜色与过滤原因一致；
5. 四片完整时显示 `GOOD 4/4` 并允许保存；
6. 重启应用后自动恢复已保存 ROI 和参数；
7. 最终安装高度和现场光照下连续识别四片。
