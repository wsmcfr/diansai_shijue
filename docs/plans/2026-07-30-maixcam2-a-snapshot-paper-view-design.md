# MaixCAM2 A版单次快照与纸面专用视图设计

## 目标

在固定机位下，程序只在连续三帧稳定后采集一次碎片快照。后续拼图求解完全使用该快照，实时轮廓抖动不再改变输入；正常界面只显示已经标定的黑色A4纸区域，纸外龙门架和地面不进入预览或检测。

## 已确认约束

| 项目 | 约束 |
|---|---|
| 硬件 | MaixCAM2固定安装，采集优先1280×960，屏幕640×480 |
| 纸面 | 支持210×297mm竖放和297×210mm横放，四角已经通过AUTO ROI或手动方式锁定 |
| 机械区域 | 黄色区域仍是电机可达范围，竖放210×230mm、横放230×210mm |
| 检测范围 | 继续使用黄色机械四边形作为可操作碎片掩膜，它是完整A4内部更严格的安全范围 |
| 坐标 | 识别、Homography和机械规划继续使用原始相机坐标与纸面毫米坐标 |
| 版本边界 | 只修改`maixcam2_app_A_quad/`，稳定版和B版业务源码保持不变 |

## 状态设计

| 状态 | 进入条件 | 使用的数据 | 退出条件 |
|---|---|---|---|
| `SEARCHING` | 启动、切换模式、再次点击当前模式、进入或退出CAL | 当前实时检测结果 | 连续三帧几何稳定 |
| `LOCKED_SOLVING` | 稳定门达到3/3 | 第3稳定帧的深复制快照 | 求解成功、确定失败或超时 |
| `LOCKED_RESULT` | 求解结束 | 同一份锁定快照和缓存规划 | 用户再次点击KNOWN/UNKNOWN、切换WHITE/CARD或进入CAL |

快照只包含完整且位于红线上方的1～4片可操作碎片。求解期间仍读取相机以保持触摸和纸面画面刷新，但正常页停止重复运行分割和轮廓提取；锁定数据不会被替换或重启。进入CAL、手动重拍或缺少缓存时才恢复实时检测。无首解超时将作为锁定失败保留，不再自动等待三帧并循环搜索。

## 纸面专用显示

正常界面在存在已保存`paper_quad`时，把四角透视映射到640×480画布中的等比例A4矩形：竖放按210:297居中并保留左右黑边，横放按297:210居中并保留上下黑边。画布矩形外强制为黑色，因此不会显示纸外场景。

显示透视仅用于预览：碎片轮廓、黄色机械区、红色分界线和下半区规划目标通过同一显示Homography变换后叠加。识别仍在原始相机帧和四边形掩膜中完成，不改变面积阈值、毫米反算或机械坐标。

未完成首次标定时保留现有整帧兼容视图，使用户仍能进入CAL并完成AUTO ROI。

## 交互设计

- 第1～2稳定帧显示实时轮廓和`STABLE 1/3`、`STABLE 2/3`。
- 达到第3帧后，界面改画锁定轮廓并显示`LOCKED SOLVING ...`。
- 成功后继续显示锁定轮廓及下半区目标；失败或超时继续显示锁定轮廓和具体原因。
- 再次点击当前`UNKNOWN`或`KNOWN`按钮执行重新采集；切换WHITE/CARD、进入CAL也会清除旧快照。

## 测试策略

1. 运行器测试证明锁定后忽略后续坐标变化，超时后不自动重拍，显式reset后才重新采集。
2. 显示测试证明纸外高亮像素为黑色、横竖纸面比例正确、锁定轮廓使用同一Homography落在纸面内容区。
3. 入口契约测试证明主循环把锁定快照传给叠加层，同模式按钮也会重置运行器。
4. 运行A版定向测试、项目全量测试、`compileall`和发布包结构测试。

## 风险与边界

- 单次锁定不会缩短旧组合搜索的纯计算时间，但会消除超时后不断换轮廓重试造成的不确定性。
- 如果锁定帧本身轮廓错误，程序会稳定地显示失败；用户需要重新摆放或调阈值后再次点击模式按钮采集。
- 透视展开仅改变显示。碎片与纸面高度差引起的视差仍需通过五点标准片检查，不能由显示变换消除。
