# MaixCAM2 AUTO ROI 自适应四角设计

## 现场证据

实机日志为`no_candidate`，49个暗色轮廓中44个面积过小，剩余5个全部在四角门失败；
三条轮廓被近似为5角、两条为6角。最大轮廓面积26.4%，因此距离、面积上限、矩形度
和置信度都不是当前失败点。

## 采用方案

1. 保留2%周长的严格`approxPolyDP`作为第一候选，干净四角行为不变。
2. 严格候选不是四角时，按2.5%、3%、3.5%、4%、5%依次重试。
3. 第一个有效四角只获得进入评分的资格，仍必须通过原有面积、矩形度和0.65置信度门。
4. 诊断数据记录严格顶点数和最终采用的`quad_eps`，现场可区分严格与容错成功。
5. epsilon序列集中放在`config.py`文件顶部，要求有限、正数、严格递增且不超过10%。

## 未采用方案

| 方案 | 不采用原因 |
|---|---|
| 直接降低矩形度或置信度 | 当前未进入这两道门，调整无效 |
| `minAreaRect()` | 会把透视梯形强制成旋转矩形，破坏Homography毫米坐标 |
| 无条件把5/6角删到4角 | 容易把龙门架或其它暗色物体强行变成纸张 |
| 调整Otsu阈值 | 当前已经稳定分出主要暗色轮廓，没有证据表明阈值122是根因 |

## 验证

- 合成5角和6角纸面在2%失败；经过真实模糊和Otsu后，2.5%仍保留额外角，3%作为首个有效比例恢复为正确四角。
- 干净A4仍采用2%。
- 非法epsilon配置明确报错。
- 成功日志包含`strict_vertices`和`quad_eps`。
- A/B全量、A版编译和发布物逐字节一致性全部通过。
