# MaixCAM2 A版求解轮廓清理与START确认门设计

## 目标

解决WHITE实机轮廓中2～10mm伪短边破坏GRAPH整边连接的问题，并把正常页改为完全待机：用户选择模式和材料后，只有点击`START`才运行碎片分割、连续稳定帧与拼装求解。

## 已确认交互

顶部按钮固定为：

```text
KNOWN | UNKNOWN | WHITE/SAVE | START | CAL
```

状态规则：

| 操作 | 状态变化 |
|---|---|
| 程序启动 | 默认选择UNKNOWN WHITE，但不运行碎片检测，显示`PRESS START` |
| 点击KNOWN或UNKNOWN | 只切换模式，取消活动检测并清除旧快照、任务和结果 |
| 点击WHITE或CARD | 只切换UNKNOWN材料，取消活动检测并清除旧状态 |
| 点击START | 清除旧快照后开始视觉分割、连续3帧稳定和对应模式求解 |
| 求解完成后再次点击START | 使用当前模式和材料重新采集 |
| KNOWN未START时点击SAVE | 不检测、不保存，显示`PRESS START` |
| 进入或退出CAL | 取消正常页检测；返回正常页后必须重新点击START |

完全待机时仍持续采集相机画面用于显示和触摸，但不调用碎片二值分割、轮廓提取、模板匹配或拼装器。CAL页面不受START门限制，继续实时执行ROI、MASK、RESULT和MEASURE所需分析。

## WHITE求解轮廓清理

在`assembly_planner.py`文件顶部现场常量区增加：

```python
UNKNOWN_WHITE_SOLVER_MIN_EDGE_MM = 12.0
```

规则如下：

1. 仅对UNKNOWN WHITE的求解副本生效；UNKNOWN CARD、KNOWN、屏幕原始轮廓和持久模板不改变。
2. 设置为`0.0`时完全关闭清理。
3. 对3～5点毫米多边形反复寻找短于门槛的最短边，至少保留3个顶点。
4. 对短边两个端点分别计算“删除该点后，点到相邻新弦线的距离”，删除几何变形较小的端点。
5. 每次删除后重新计算边长，直到所有边达到门槛或只剩3点。
6. 返回独立数组，不修改视觉模块传入的`vertices_mm`。
7. 非有限、退化或清理后面积无效的结果不进入求解，返回现有结构化几何失败。

该算法使用题目“每条真实边不短于20mm”的物理约束。默认12mm在真实最短边下留出8mm余量，用于去除日志中2.3、6.7和10.4mm一类伪短边，不使用全局较大的`approxPolyDP`误删真实五边形角。

## 数据流

```text
模式/材料选择
    -> capture_armed=False，正常页完全待机
    -> 点击START
    -> capture_armed=True
    -> 高分辨率碎片分割
    -> 连续3帧稳定并锁定原始轮廓
    -> UNKNOWN WHITE创建清理后的求解副本
    -> GRAPH使用清理副本执行严格/容错路径
    -> 无解时恢复原始锁定顶点进入分段边兜底
    -> 缓存结果，屏幕继续绘制原始锁定轮廓与目标
```

GRAPH优先使用清理副本争取快速整边连接；兜底恢复原始锁定顶点。回归证据表明，某些
伪短边同时携带边界面积，删除任一端点都会使原本88.8%可接受布局变成填充失败。因此
清理只作为不会降低原有成功率的快路径优化，不能覆盖保底几何输入。

## 调试输出

当`UNKNOWN_SOLVER_DEBUG=True`时，在原始`PIECE`日志之后输出每片清理摘要：

```text
[SOLVER] CLEAN id=U2 vertices=5->4 removed=1 min_edge=6.7
```

关闭调试开关后不计算日志字符串且不打印。原始`PIECE vertices_mm/edges_mm`继续保留，便于对比清理前后效果。

## UI与错误处理

- `START`按钮位于第三按钮与右上角`CAL`之间，保持至少6px间隔。
- 未启动时`START`为灰色，启动后为绿色；KNOWN/UNKNOWN仍显示当前选择。
- 未启动状态使用空检测结果绘制，不显示旧片数、旧红点或旧目标。
- START后的视觉异常继续显示现有`VISION ERROR 类型`，不自动切换模式。
- 切换模式、材料或CAL必须取消活动`UnknownSolveJob`，不允许旧结果回写新上下文。
- KNOWN SAVE只有在当前START会话已经得到实时检测结果时允许执行。

## 测试范围

1. 2.3、6.7和10.4mm伪短边在12mm门槛下被合并，所有真实20mm以上边保持。
2. 清理不修改输入，至少保留3点；门槛0关闭清理。
3. WHITE的GRAPH使用清理结果；WHITE/CARD兜底继续使用原顶点，CARD保留边缘花纹。
4. 正常页初始、模式切换、材料切换、CAL往返均为完全待机。
5. 只有START后才调用视觉分析与`AssemblyRuntime.update()`。
6. 未START的KNOWN SAVE返回`PRESS START`，START后保持既有登记流程。
7. 640×480按钮不重叠，触摸命中与绘制文字一致。
8. A版全量、编译、平铺发布包与B版固定哈希边界通过。
