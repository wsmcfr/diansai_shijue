# MaixCAM2 A版 GRAPH_AUTO 快路径与倾斜相机标定设计

## 1. 背景与证据

现场三片白色碎片已经能形成三个完整轮廓，但A版UNKNOWN会超过截止时间仍得不到
规划。用户提供的K230参考程序在同一组三片上输出`GRAPH_AUTO count=3`，说明它不仅
完成轮廓识别，也完成了自动拼装。

同输入PC基准表明，参考实现的优势来自求解结构而不是简单放宽参数：

| 每顶点随机误差 | A版成功率 | 参考图匹配成功率 | A版平均耗时 | 参考平均耗时 |
|---:|---:|---:|---:|---:|
| 0mm | 20/20 | 20/20 | 6.69ms | 3.17ms |
| 1.0mm | 17/20 | 20/20 | 15.46ms | 3.98ms |
| 1.5mm | 13/20 | 19/20 | 26.68ms | 6.24ms |
| 2.0mm | 4/20 | 18/20 | 40.35ms | 10.55ms |

把A版边长容差从2.5mm直接增到6～12mm会让边候选、完整组合和耗时成倍增加，不能
解决现场问题。因此采用用户确认的混合方案：移植有界连接图快路径，但保留A版毫米
尺寸、填充和重叠验收，快路径失败后继续使用现有增量搜索。

## 2. Homography 数据流

A版已经保存完整A4的四个像素角点，并用210×297mm物理四角建立逆单应矩阵。倾斜
相机下的碎片像素顶点先由`image_points_to_paper_mm()`映射为纸面毫米坐标，求解器只
处理毫米多边形：

```text
相机像素轮廓
  -> 已锁定A4四角
  -> 逆Homography
  -> A4纸面毫米顶点
  -> GRAPH_AUTO
  -> 下半区毫米目标
  -> 正Homography绘回相机画面
```

只要A4和碎片表面近似共面、四角完整可见，摄像头可以倾斜。Homography不负责镜头
径向畸变；若真实100×60mm标准片在纸面中心和四周的误差超过2mm，需要另做相机内参
和畸变校正。碎片表面明显高于纸面时还会产生视差，应以碎片顶面作为标定平面或降低
倾角。

## 3. GRAPH_AUTO 快路径

快路径只用于UNKNOWN的WHITE子模式，CARD继续使用现有纹理择优路径。

1. 从每片3～5边毫米多边形建立无向整边候选，使用相对边长误差排序。
2. 候选最多保留32条，避免错误轮廓扩大组合数量。
3. 三片优先枚举2条连接边，四片优先枚举3条连接边；必要时允许多一条闭环边。
4. 每条物理边在一个组合内只能使用一次，每片度数不超过3，组合必须连通。
5. 最多检查90组连接关系。
6. 以第0片为单位位姿，通过BFS一次传播其余碎片旋转和平移；闭环重复到达时计算
   位姿闭合误差。
7. 先按边长误差、闭合误差和矩形紧凑度排序，再让排名靠前的候选进入A版现有
   `_canonicalize_complete_layout()`毫米硬验收。
8. WHITE找到第一个硬验收合格的图布局立即返回；没有合格结果时进入原增量搜索。

快路径不缩放、不镜像碎片。检测边长不完全相等时以边中点对齐，把误差平均分配到
两个端点，避免参考程序单端点对齐造成全部误差集中在一端。

## 4. 安全边界与诊断

参考程序的最终评分不限制真实毫米尺寸，并允许更大的缺口，不能原样作为机械目标。
A版继续执行现有目标长边88～122mm、短边48～92mm、填充率和重叠率硬门槛。

新增整数诊断：

| 字段 | 含义 |
|---|---|
| `graph_edge_candidates` | 截断前后实际采用的连接边候选数量 |
| `graph_matching_sets` | 已构造的连通边组合数量 |
| `graph_layouts_checked` | 已传播并进行完整验收的布局数量 |
| `graph_fast_path` | 结果来自图快路径时为1，否则为0 |

图快路径异常不得穿透相机主循环；几何无解时正常回退，输入字段损坏继续返回既有
`unknown_geometry_invalid`。旧搜索、CARD、KNOWN、稳定版和B版业务源码均不改变。

## 5. 验收

- 同一组三片物理多边形映射到正视与倾斜A4像素四边形后，反算毫米坐标和规划结果一致。
- 现场近似两四边形加一三角形在1～2mm确定性顶点误差下能通过图快路径。
- 非矩形碎片、断开的边图和明显错误尺寸不能被图快路径误接受。
- 图边候选不超过32，连通组合不超过90。
- WHITE优先使用图快路径，图失败时原搜索仍能给出既有成功或结构化失败。
- CARD行为、KNOWN登记、无首解自动重试、全量测试、平铺ZIP和哈希边界均不回归。
