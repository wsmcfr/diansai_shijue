# MaixCAM2 A版UNKNOWN多轮廓候选求解设计

## 目标

修复同一组默认四片在KNOWN模式能够规划、在UNKNOWN WHITE模式却长期超时的问题。UNKNOWN必须完全不读取、不匹配、也不回退到KNOWN模板，只根据锁定帧中1～4片碎片的当前完整轮廓独立推导接缝、旋转角和下半区目标位置。

本轮只修正UNKNOWN几何建模与求解数据流，不放宽以下最终安全门：

| 安全门 | 保持值 |
|---|---:|
| 严格填充率 | 92% |
| WHITE容错填充率 | 86% |
| 最大重叠率 | 3% |
| 目标长边 | 90～120mm的题目范围，代码现有兼容余量保持不变 |
| 目标短边 | 50～90mm的题目范围，代码现有兼容余量保持不变 |
| 碎片数量 | 1～4片 |
| 每片顶点 | 3～5个真实顶点 |

## 已确认根因

当前失败不是毫米映射或目标尺寸的首要问题。同一锁定摆放在KNOWN中能够匹配并产生规划，证明当前纸面Homography至少足以支撑该次模板匹配；UNKNOWN失败发生在重新推导几何接缝的链路中。

| 位置 | 当前行为 | 后果 |
|---|---|---|
| `puzzle_vision.approximate_polygon()` | 从`epsilon=0.006`开始，遇到第一个3～5顶点结果立即返回 | 没有比较后续更符合20mm真实边约束的候选 |
| `_clean_solver_short_edges()` | 反复删除小于12mm的最短边，直到剩余边过门 | U1/U2可能从五边形连续删成错误三角形 |
| GRAPH | 显式使用短边清理后的轮廓 | 可能损失真实边界面积和正确接缝 |
| FOUR_FAST | 显式恢复未经清理的原始轮廓 | 2.9～7.7mm伪边重新进入边图 |
| FALLBACK | 同样使用未经清理的原始轮廓 | 大量候选进入`size_reject`和`overlap_reject` |
| 现有测试 | 明确断言GRAPH清理、两个兜底保留原轮廓 | 把三条路径几何口径不一致固化成了“正确行为” |

因此不能继续只增加Beam宽度、节点数或超时时间。搜索器拿到错误且互不一致的多边形时，更多预算只会检查更多错误组合。

## 已批准架构

每片碎片同时保留两类几何数据：

```text
像素完整轮廓 contour
    ├─ outline_mm：高保真毫米轮廓，负责面积、重叠、填充率和机械中心
    └─ shape_hypotheses：最多3个三至五边候选，只负责提出接缝和刚体位姿
                                   ↓
                GRAPH -> FOUR_FAST -> FALLBACK
                                   ↓
                  始终用outline_mm执行最终硬验收
```

### 完整轮廓

`main.py`通过已经锁定的纸面Homography把`piece["contour"]`一次性转换为`outline_mm`。完整轮廓不参与接缝边枚举，避免数百个像素边界点扩大边图；它只在中间快速重叠、完整布局硬验收和机械目标构造时使用。

为限制MaixCAM2运算量，允许对完整轮廓做高保真压缩，但压缩前后面积保持率必须不低于99%，且不能强制压缩到3～5点。

### 接缝候选

视觉层遍历现有`approx_epsilon_min`至`approx_epsilon_max`的全部`approxPolyDP`结果，不再遇到第一个3～5边结果就结束。毫米映射后按以下指标评分、去重并最多保留三个候选：

1. 顶点数必须为3～5。
2. 题目真实边20mm作为主要评分依据。
3. 小于14mm的边默认进入硬拒绝；14～20mm进入短边惩罚而不是直接认定为真实边。
4. 候选相对完整轮廓的面积保持率默认不低于96%。
5. 候选边界到完整轮廓的最大偏差默认不高于3mm。
6. 尖刺、近共线重复点和自交多边形拒绝或重罚。
7. 顶点数相同且位姿归一后边界距离接近的候选只保留分数更优者。

现场宏集中放在`maixcam2_app_A_quad/assembly_planner.py`顶部：

| 宏 | 默认值 | 作用 |
|---|---:|---|
| `UNKNOWN_SHAPE_MAX_HYPOTHESES` | `3` | 每片最多保留候选数 |
| `UNKNOWN_REAL_EDGE_MIN_MM` | `20.0` | 题目真实边物理基准 |
| `UNKNOWN_EDGE_HARD_FLOOR_MM` | `14.0` | 考虑映射误差后的候选硬下限 |
| `UNKNOWN_SHAPE_AREA_RETENTION_MIN` | `0.96` | 简化候选最小面积保持率 |
| `UNKNOWN_SHAPE_MAX_DEVIATION_MM` | `3.0` | 候选最大边界偏差 |

这些宏只控制候选质量和搜索规模，不改变最终矩形验收门。

## 统一求解几何

`_solver_piece()`不再接收`clean_short_edges`开关。它为每片建立一个公共求解结构：

| 字段 | 含义 |
|---|---|
| `outline_local` | 以完整轮廓质心为公共原点的高保真轮廓 |
| `source_center` | 锁定帧中的完整轮廓毫米质心 |
| `hypotheses` | 排序后的1～3个接缝候选 |
| `hypothesis.rank` | 候选等级，0为首选 |
| `hypothesis.local_vertices` | 使用同一完整轮廓质心归一化的接缝顶点 |
| `hypothesis.edge_lengths` | 预计算边长 |
| `hypothesis.edge_features` | CARD模式对应候选边的纹理特征 |

对齐某条接缝时，算法先由简化候选计算旋转矩阵和平移向量，再把同一个刚体变换同时应用到候选顶点和`outline_local`。搜索状态必须记录每片已经选定的候选编号；同一片一旦放置，不能从另一个候选借用边。

GRAPH、FOUR_FAST和FALLBACK共用同一组求解结构、同一套接缝关系和同一套最终验收。三者只允许搜索策略不同，不再各自决定是否删除短边。

## 分级搜索与性能边界

候选关系在一个`UnknownSolveJob`中按等级逐步开放，不创建三个独立任务，也不重置活动预算或墙钟预算：

1. 优先扩展所有碎片均使用排名0候选的关系。
2. 无解后允许包含排名1候选的状态。
3. 四片仍无解才允许包含排名2候选的状态。
4. 状态排序首先比较最高候选等级和候选总分，再比较接缝误差、分段关系数量和外框紧凑度。
5. 去重键必须包含“碎片编号、候选编号、量化位姿”，防止不同候选错误合并。

1～3片不进入FOUR_FAST；第一候选正确时，边图规模和现有路径基本一致。四片继续共享现有FOURFAST 1.5秒活动预算，达到预算后进入同一个增量FALLBACK，不能重新识别或重新锁定碎片。

## 最终机械结果

简化候选只负责发现接缝。最终输出必须以完整轮廓公共质心和求解得到的刚体变换为准：

- `source_center_mm`取锁定帧完整轮廓质心。
- `target_center_mm`取同一刚体变换后的质心。
- `rotation_deg`直接由刚体旋转矩阵归一化得到。
- 目标显示轮廓使用变换后的完整轮廓。
- 下半区目标矩形放置、工作区边界和机械可达范围保持现有逻辑。

这样不会出现“接缝候选顶点删对了，但机械中心又按另一套简化顶点发生偏移”的问题。

## 失败处理和诊断

UNKNOWN增加更具体的终态原因：

| 原因 | 含义 |
|---|---|
| `shape_hypothesis_empty` | 至少一片无法生成合格的3～5边候选 |
| `edge_graph_empty` | 候选存在，但没有长度兼容接缝 |
| `layout_overlap` | 完整候选主要被重叠门拒绝 |
| `layout_size` | 完整候选主要被尺寸门拒绝 |
| `layout_fill` | 完整候选主要被填充率门拒绝 |
| `solver_timeout` | 候选存在，但总预算内未完成搜索 |

调试开启时，每次锁定只输出一次候选摘要和最终选用候选：

```text
[SOLVER] SHAPE id=U1 candidates=3 best_vertices=4 min_edge=21.3 score=0.18
[SOLVER] TIER rank=1 edges=18 states=32
[SOLVER] ACCEPT shapes=U1:0,U2:1,U3:0,U4:0
```

关闭`UNKNOWN_SOLVER_DEBUG`后不构造这些字符串。失败只能返回不带机械目标的失败规划；超时时只有已经通过完整硬验收的`best_plan`可以返回。

## 测试设计

1. 用真实四边形叠加2.9～7.7mm伪短边，验证候选中包含正确四边形。
2. 真实三角形、四边形和五边形必须分别保留，不能全部清理成三角形。
3. 当前实机三片日志继续成功，第一候选正确时不能进入第二候选层。
4. 默认KNOWN四片改用UNKNOWN输入时，在不读取模板的条件下必须成功。
5. 1、2、3、4片参数化用例全部通过。
6. 92%/86%、3%重叠、目标尺寸和逐片外边硬门全部保留。
7. UNKNOWN测试把KNOWN匹配和模板读取入口替换成“调用即抛错”，证明无生产依赖。
8. GRAPH、FOURFAST和FALLBACK必须收到同一个候选结构。
9. 调试关闭时不构造候选预览或日志字符串。
10. A版全量、编译、平铺发布包通过；稳定版与B版源码和发布包哈希保持不变。
