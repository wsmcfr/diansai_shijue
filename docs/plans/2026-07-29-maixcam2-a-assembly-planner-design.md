# MaixCAM2 A版机械区域与拼装规划器设计

## 1. 目标与边界

本次只升级 `maixcam2_app_A_quad/`，版本从 `v1.1.1` 提升到 `v1.2.0`。B版透视展开和稳定版保持字节级不变。视觉模块负责识别、毫米坐标换算、拼装求解和屏幕提示，不在本轮定义电机通信协议。

| 项目 | 已确认约束 |
|---|---|
| 相机与纸张 | MaixCAM2和纵向黑色A4纸均固定，完整A4为210×297mm |
| 机械范围 | XY最大230×230mm；纸宽只有210mm，默认取纸面中间210×230mm |
| 初始区域 | 碎片随机、不重叠地位于分界线上方，纸面内可任意角度旋转，不允许镜像翻面 |
| 已知题 | 四片形状固定，目标布局固定为100×60mm；赛前保存一次正确布局 |
| 未知题 | 1～4片，每片3～5边且每边不短于20mm，目标矩形90×50mm～120×90mm |
| 牌面题 | 几何正确之外，相邻接缝图案还必须连续 |
| 时序 | 连续稳定若干帧后只求解一次并缓存，避免每帧重复搜索 |

## 2. 坐标系统

蓝色框始终表示完整A4。系统以完整A4左上角为原点，短边方向为X轴0～210mm，长边方向为Y轴0～297mm。所有像素点通过蓝框四角求出的单应矩阵逐点转换，禁止用单一“毫米/像素”比例代替透视映射。

黄色机械区域改为五个现场参数：`WORK_X`、`WORK_Y`、`WORK_W`、`WORK_H`、`SPLIT_Y`。默认值为 `0、33.5、210、230、148.5mm`。区域必须完整位于A4内，且宽不超过210mm、高不超过230mm；分界线必须位于机械区域内部。原来的 `INSET` 字段只保留用于V2设置迁移和旧测试兼容，不再决定A版黄色区域。

## 3. 调参界面

ROI、MASK、RESULT页面保持简单操作，底部五个固定触摸槽改为：`AUTO ROI`、`-`、当前机械参数、`+`、`LOCK ROI`。点击中间参数按钮按 `X→Y→W→H→SPLIT` 循环，`-`和`+`以0.5mm步进调整。这样宽高可以直接增大或缩小，不再出现“INSET方向与区域大小相反”的歧义。

ADV页继续只调阈值、最小面积、开运算和闭运算。自动识别黑纸失败时显示 `AUTO ROI FAIL` 并保留上次四角；锁定时仍允许黑纸上已有1～4片完整碎片。ROI预览同时画蓝色完整A4、黄色机械区域和红色毫米分界线。

## 4. 单帧视觉数据

A版识别结果保留原相机轮廓、顶点和中心，并新增：

| 字段 | 含义 |
|---|---|
| `vertices_mm` | 每个拟合顶点在完整A4上的毫米坐标 |
| `center_mm` | 碎片质心的完整A4毫米坐标 |
| `region` | `upper`、`lower`或`crossing`，按全部顶点和毫米分界线判断 |
| `edge_features` | 每条边内侧的颜色与灰度梯度采样，用于扑克牌接缝评分 |

只把 `complete=True` 且位于上半区的碎片送入自动拼装求解。跨线或触碰黄色区域边缘的轮廓只显示诊断，不进入机械目标。

## 5. 已知四片规划

赛前把四片按正确关系摆成目标矩形，并保留1～2mm黑缝以便视觉仍得到四个独立轮廓，然后在KNOWN模式按SAVE。登记过程保存每片旋转不变形状描述子，以及相对于100×60mm目标矩形原点的目标多边形。

运行时先执行最多24种的一对一模板全局匹配，再对每片观测多边形和已保存目标多边形做不含镜像的刚体对齐，直接得到目标中心与纸面内旋转角。目标100×60mm矩形自动居中放在黄色区域的下半区；目标区空间不足时返回明确失败，不输出越界坐标。

## 6. 未知碎片规划

未知模式不预存形状。求解器先把每片毫米多边形归一化到自身质心，再选择一片固定方向作为基准。回溯过程中枚举“未放置碎片的一条边”与“已放置碎片的一条边”反向重合的刚体变换，仅接受长度误差在容差内、无明显重叠的候选。

当全部碎片放置后，把组合轮廓旋正并用毫米栅格验证：目标边长处于90×50mm～120×90mm、碎片重叠率受限、矩形填充率足够高、内部缝隙足够小。白片按几何误差排序；检测到边缘具有明显纹理时，再使用反向接缝颜色和梯度连续性作为排序项。节点数和候选数都有硬上限，失败时显示 `NO ASSEMBLY`，不会无限搜索。

## 7. 稳定帧、缓存与显示

正常界面连续三帧检测到相同数量、相同顶点数且毫米中心位移在容差内后才触发一次求解。求解结果按识别模式缓存；切换KNOWN/UNKNOWN、重新保存模板、进入CAL或检测结构发生明显变化时清空缓存。

下半区叠加显示目标矩形、每片目标轮廓、编号、当前中心到目标中心的箭头、目标毫米坐标和旋转增量。红色分界线从设置直接映射绘制，不再依赖图像中红线检测。

## 8. 错误处理与验收

设置V3能够从A版V2文件迁移：旧 `INSET=i` 转换为 `X=i、Y=33.5+i、W=210-2i、H=230-2i`，分界线使用148.5mm。损坏设置、退化四边形、目标区域不足、模板缺少布局、求解超限均返回屏幕状态，不使主循环退出。

PC验收包括每轮红绿TDD、全量pytest、compileall、A版平铺ZIP导入、稳定版9项SHA256以及B版发布包SHA256。相机真实曝光、触摸、帧率和机械误差仍需MaixCAM2实机验证。
