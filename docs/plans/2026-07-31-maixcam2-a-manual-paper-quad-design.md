# MaixCAM2 A版蓝框手动标定设计

## 1. 目标

在A版CAL界面的ROI页增加AUTO/MANUAL双模式。AUTO继续执行现有黑色A4纸定位；MANUAL允许用户通过屏幕上的减号、参数按钮和加号，整体调节蓝色A4四边形的位置、宽度和高度。AUTO略有误差时以AUTO结果为初值精调，AUTO失败时仍能使用历史蓝框或居中A4初始框完成标定。

本功能只改变A版调参会话和蓝框交互，不改变KNOWN、UNKNOWN、FOUR求解器、UART4协议、毫米坐标定义、稳定版或B版业务代码。

## 2. 已确认需求

| 项目 | 确认结果 |
|---|---|
| 手动调节方式 | 整体`X/Y/W/H`，不逐角点调节 |
| 透视处理 | 保留AUTO蓝框已有的梯形透视关系 |
| AUTO失败回退 | 优先使用会话中的上次保存蓝框；不存在时生成居中A4比例框 |
| 默认蓝黄关系 | AUTO成功、首次生成手动框或进入手动标定时，黄色工作区默认等于完整蓝框 |
| 保存方式 | 继续使用`LOCK ROI`；未锁定的会话改动不写入磁盘 |
| 按钮布局 | 保留六个底部触摸槽以及`SEND A4` |
| 步进 | 支持`1/5/10px`，默认`5px` |

## 3. 界面结构

### 3.1 页面职责

| 页面 | 参数职责 |
|---|---|
| ROI | 蓝色完整A4框的AUTO/MANUAL模式、`X/Y/W/H/STEP`手动参数 |
| MASK/RESULT/MEASURE | 保留黄色毫米工作区`X/Y/W/H/SPLIT/PAPER`调节 |
| ADV | 保留阈值、面积、开闭运算和分割参数保存 |

这样可以避免把蓝框参数和黄色工作区参数放在同一个十余项循环中。用户在ROI页看到蓝框就只修改蓝框，在MASK/RESULT页看到分割效果时再修改黄色检测范围。

### 3.2 ROI页六槽交互

| 槽位 | 标签/动作 |
|---:|---|
| 1 | `AUTO ROI`：对当前帧执行一次AUTO定位；成功后更新会话蓝框，失败时保留当前蓝框 |
| 2 | `-`：按当前参数向负方向调整 |
| 3 | 循环选择`MODE → X → Y → W → H → STEP` |
| 4 | `+`：按当前参数向正方向调整 |
| 5 | `LOCK ROI`：通过现有门槛后保存蓝框和纸面参数 |
| 6 | `SEND A4`：发送当前已标定A4毫米边界帧 |

选择`MODE`时，`-`和`+`都在AUTO与MANUAL之间切换。AUTO模式下`X/Y/W/H`不修改蓝框并显示`SWITCH MANUAL`；MANUAL模式下才允许几何调整。选择`STEP`时，`-`和`+`在`1/5/10px`中循环。

## 4. 状态与数据流

`roi_mode`、当前蓝框参数项和像素步进均属于`CalibrationSession`，只在当前CAL会话中存在，不加入JSON设置版本。真正需要持久化的几何数据仍只有现有`paper_quad`。

```text
进入CAL
  -> 加载已保存paper_quad到会话副本
  -> ROI默认处于AUTO

按AUTO ROI
  -> 当前帧运行locate_black_paper
  -> 成功：更新paper_quad、方向和完整黄色工作区
  -> 失败：保留当前paper_quad并显示AUTO ROI FAIL

切换MANUAL
  -> 有paper_quad：以当前蓝框为初值
  -> 无paper_quad：按当前PAPER方向生成居中A4比例初始框
  -> 黄色工作区重置为完整A4

按-/+
  -> 生成候选四边形
  -> 校验画面边界、最小尺寸、凸性和连续点序
  -> 通过：仅更新会话paper_quad
  -> 失败：保持旧值并显示ROI LIMIT

按LOCK ROI
  -> 使用现有1至4片完整轮廓门槛
  -> merge_paper_settings并保存
```

AUTO按钮在MANUAL模式下仍可使用。AUTO成功后保留新蓝框并把模式切回AUTO；用户若仍需修正，再把MODE切回MANUAL。AUTO失败不会清空手动框。

## 5. 手动几何算法

输入四角继续使用现有连续顺序：左上、右上、右下、左下。

### 5.1 平移

- `X- / X+`：四个角点的图像X坐标同时减少或增加当前步进。
- `Y- / Y+`：四个角点的图像Y坐标同时减少或增加当前步进。

平移使用相机分析分辨率的像素坐标，显示层继续按已有比例映射到640×480屏幕，因此高分辨率分析不会丢失坐标精度。

### 5.2 宽高调节

- `W`：分别围绕上边中点和下边中点等比例缩放左右端点。
- `H`：分别围绕左边中点和右边中点等比例缩放上下端点。
- 缩放比例依据两条对应边的平均长度计算，使每次操作的平均宽或平均高改变约`2 × STEP`像素。

该方法保留四条边当前的方向和上下边、左右边之间的透视比例，不会把AUTO得到的梯形强制变成轴对齐矩形。

### 5.3 无历史蓝框时的初始框

初始框按当前`paper_orientation`选择210:297或297:210比例，在相机画面中央以80%可用宽高等比放置，并至少保留10%画面边距。初始框生成后立即经过现有设置校验。

## 6. 安全门与错误显示

| 条件 | 行为 |
|---|---|
| 任一角点越出相机画面 | 拒绝本次调整，显示`ROI LIMIT` |
| 平均宽或高小于80px | 拒绝本次调整，显示`ROI LIMIT` |
| 四边形变成凹形、交叉或退化 | 拒绝本次调整，显示`ROI LIMIT` |
| AUTO失败 | 显示`AUTO ROI FAIL`，不覆盖当前手动框或历史框 |
| AUTO模式调整X/Y/W/H | 不修改蓝框，显示`SWITCH MANUAL` |
| 没有蓝框时发送A4 | 保持现有`ROI NOT SET` |
| 未达到LOCK轮廓门槛 | 保持现有`ROI NEEDS 1-4 COMPLETE` |

蓝框变化会重置MEASURE稳定窗口，防止新旧坐标混入同一个抖动统计窗口。

## 7. 默认蓝框与黄框关系

黄色框不是独立像素矩形，而是通过`paper_quad`上的A4毫米Homography映射得到。AUTO成功或MANUAL初始化时，把毫米工作区设置为完整纸面：

- 竖放：`(0, 0, 210, 297)mm`
- 横放：`(0, 0, 297, 210)mm`

因此蓝框和黄色框默认完全重合。之后用户在MASK/RESULT页面主动修改黄色工作区时，两者才会分开；再移动蓝框时，黄色区域仍随同一纸面Homography移动。
