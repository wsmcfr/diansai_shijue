# MaixCAM2 A版高稳定快速拼图设计

## 1. 目标与边界

本次只修改A版 `maixcam2_app_A_quad/`，解决实机已经确认的三类问题：640x480下2mm黑缝只有约2像素并被模糊/闭运算连接；KNOWN SAVE错误地对随机上半区碎片执行未知拼图搜索；UNKNOWN候选搜索在MaixCAM2上两分钟仍只能推进到数百节点。

稳定版 `maixcam2_app/` 和B版 `maixcam2_app_B_warp/` 保持不变。A4仍以完整纸张左上角为毫米原点，机械区域仍为可调的230x230mm区域，屏幕触摸坐标继续使用640x480。

| 指标 | 目标值 |
|---|---:|
| 最小纸面采样密度 | 不低于2 px/mm时显示PASS |
| 2mm黑缝 | 高分辨率掩膜中至少4像素 |
| 连续检测 | 10帧数量一致且几何抖动不超过1mm |
| KNOWN登记 | 不执行拼图搜索，单帧完成 |
| KNOWN运行匹配 | 最多24种模板分配，目标小于0.2秒 |
| UNKNOWN四片求解 | 目标小于2秒，5秒墙钟硬超时 |

## 2. 高分辨率识别与低分辨率显示

相机默认采集1280x960，若设备不支持则明确回退640x480并显示 `RES LOW`。识别、纸张定位、轮廓拟合和毫米反算全部使用采集坐标；最终预览等比缩放到640x480后再绘制按钮和状态栏。触摸事件只作用于显示坐标，不参与识别坐标计算。

持久化ROI和A4四角改用0到1的归一化坐标保存，加载旧V3设置时按旧640x480归一化后迁移到新采集分辨率。这样AUTO ROI、重启恢复和未来分辨率切换不会把旧像素坐标误用到新画面。

正常帧只处理A4四边形的外接矩形，不对整张1280x960画面执行高成本形态学操作。屏幕继续显示完整视场，以便观察龙门架和纸张位置。

## 3. 不连接相邻碎片的分割

默认参数改为3x3高斯、3x3开运算、1x1闭运算。闭运算为1表示不改变外轮廓，避免跨越黑缝。牌面内部孔洞通过“保持每个外部连通域边界并填充内部孔洞”处理，不能通过膨胀或大核闭运算填孔。

调参页继续允许1/3/5等核值，但质量判断增加物理保护：由A4四边长度计算局部最小px/mm，再把闭运算半径换算成毫米；若它可能覆盖2mm间隙，显示 `GAP RISK`，不允许保存为GOOD。

轮廓拟合使用高分辨率原始外轮廓。三至五边候选不再返回第一个满足顶点数的 `approxPolyDP` 结果，而按轮廓残差、最短边、面积保持率和连续帧一致性评分，降低顶点数在相邻帧间跳变。

## 4. 标定质量页面

CAL新增 `MEASURE` 页面，直接显示可验证的数据，而不是只显示蓝框是否好看：

| 字段 | 含义 | PASS条件 |
|---|---|---|
| `SCALE` | A4四边得到的最小像素/毫米 | >=2.0 px/mm |
| `GAP` | 相邻白色连通域的最小黑缝像素 | >=4 px |
| `STABLE` | 最近10帧碎片数量一致次数 | 10/10 |
| `JITTER` | 关联碎片中心和顶点的最大毫米抖动 | <=1.0mm |
| `RECT` | 可选100x60mm标准卡的测量尺寸 | 两边误差<=1.5mm |

A4四角本身必然被单应矩阵映射为210x297mm，不能作为精度证据。现场需放置一张真实测量过的100x60mm白色标准卡，分别在工作区上、下、左、右、中心检查尺寸。若边缘误差明显大于中心，说明镜头畸变需要独立标定；PnP不能代替分割，也不能提高像素分辨率。

## 5. KNOWN直接登记

赛前把四片已知碎片手工拼成正确100x60mm布局，放在红线下方且每片之间保留可识别黑缝，进入KNOWN后按SAVE。登记器只接收四个 `complete=True` 且 `region=lower` 的碎片，验证联合外接矩形、填充率、重叠率和100x60mm尺寸，然后把每片目标多边形直接归一到精确100x60mm并保存K1到K4模板。

这条路径不调用UNKNOWN求解器，不创建跨帧SAVE任务。成功后立即显示 `KNOWN SAVED PLAN OK`；片数、区域、尺寸或填充率不合格时显示具体原因并保留旧模板。正式运行时，四片随机摆放在上半区，沿用现有最多24种形状模板分配，直接得到下半区目标。

## 6. UNKNOWN快速边图求解

网上模拟器的边长候选、邻接图和全局矩形评分思想保留，但不复制其最多80候选后做组合穷举的实现。PC基准表明原实现对当前四片输入需5.78到12.61秒，不能直接部署。

新求解器分四步：

1. 为每片预计算局部顶点、边长、边方向、相邻内角和可选纹理特征。
2. 为每对碎片预计算完整边和T形分段边候选，每个碎片对只保留分数最好的有限候选。
3. 用限宽优先搜索逐步连接尚未放置碎片；使用包围框、接触长度、线段相交和面积守恒剪枝，不在每个扩展中重复栅格化。
4. 仅对完整布局栅格化一次，检查目标尺寸范围、填充率、重叠率和矩形外轮廓；白片首个高质量解立即返回，纹理片只比较有限个完整解。

搜索同时受候选数、状态数和5秒墙钟限制。状态栏显示 `C=<候选工作量> S=<展开状态> T=<毫秒>`，避免旧版N长时间不变。超时返回 `SOLVER_TIMEOUT`，不能继续占用比赛时间。

## 7. 坐标与PnP边界

平面坐标继续采用A4单应矩阵。它适合固定相机和共面纸片，且输出可直接用于二维龙门架。PnP只在后续需要相机三维姿态、纸面Z高度或手眼标定时使用；它不参与碎片分割和拼图组合。

毫米准确性的现场验收依次为：实测黑纸尺寸、锁定完整四角、高分辨率SCALE通过、100x60标准片五位置测量、最后才进行电机点位校正。若标准片尺寸误差合格而电机落点仍有固定偏差，应校正相机毫米到电机毫米的二维刚体/仿射关系，不能回头修改碎片阈值。

## 8. 失败保护与发布

加载旧设置、相机高分辨率打开失败、标准片不合格、KNOWN登记失败、UNKNOWN超时和模板写入失败都转换成屏幕状态。任何失败结果不得携带机械目标，也不得覆盖旧模板。

测试覆盖V3到V4分辨率迁移、2mm缝隙不连接、孔洞填充、SCALE/GAP/JITTER质量、下半区KNOWN直存、随机上半区KNOWN快速匹配、UNKNOWN各类2到4片、无解超时和MaixVision平铺ZIP。最终只发布新的A版ZIP，B版和稳定版哈希必须保持不变。
