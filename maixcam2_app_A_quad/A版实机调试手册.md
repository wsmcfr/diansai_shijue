# A版（四边形掩膜）MaixCAM2实机调试手册

> 适用程序：`maixcam2_app_A_quad` v1.10.0
> 适用结构：固定MaixCAM2、横放或竖放黑色A4纸、白色碎片、230×230mm电机范围  
> 发布包：`dist/diansai_quad-v1.10.0.zip`

## 1. 调试目标

调试完成后，系统应同时满足以下条件：

| 项目 | 合格标准 |
|---|---|
| 完整A4定位 | 蓝色/青色四边形贴合黑色A4纸的四条边 |
| 机械有效区域 | 竖放默认210×230mm；横放默认230×210mm，均对应真实电机可达纸面 |
| 上下区域 | 红线位于设定的`SPLIT`毫米位置，碎片区在上、拼装区在下 |
| 二值分割 | `MASK`中碎片为白色、黑纸为黑色，碎片互相分离 |
| 轮廓识别 | 4片调参样片均为绿色完整轮廓，无橙、红、紫异常轮廓 |
| 参数保存 | ADV页达到`GOOD 4/4`并显示`ADV SAVED` |
| ROI保存 | 显示`ROI LOCKED`，重启后蓝框和黄框仍正确 |
| 规划输出 | 碎片稳定后依次显示`STABLE 1/3`、`STABLE 2/3`、`LOCKED SOLVING ...`、`LOCKED PLAN OK N=...` |
| 正常页画面 | 只显示已标定A4纸面，竖放左右或横放上下允许出现纯黑等比例留边 |
| 完全待机 | 启动、切换模式/材料或退出CAL后显示`PRESS START`，未按START时没有碎片轮廓和稳定计数 |

当前A版只负责识别、拼装求解和显示A4毫米坐标，还没有接入电机通信。第一次联调电机时必须先空载或抬起夹具，核对坐标方向后再抓取碎片。

## 2. 调试前准备

### 2.1 硬件准备

| 项目 | 要求 |
|---|---|
| 相机 | 固定在最终安装位置，调试完成后不得再移动或转动 |
| 安装高度 | 按最终机械结构固定；当前结构高度约100mm时，应在该高度完成全部标定 |
| 黑纸 | 标准A4，实际尺寸210×297mm，铺平并固定，四角尽量完整可见 |
| 光源 | 使用稳定、均匀、无频闪的照明，避免黑纸强反光和白片过曝 |
| 龙门架 | 先停到固定停车位，尽量不要遮挡黑纸边缘或碎片区域 |
| 碎片 | 调参时准备4片，互不接触、互不重叠，每片边缘完整可见 |
| 辅助工具 | 直尺、黑胶带、记录表；电机联调时准备急停或断电手段 |

### 2.2 现场固定原则

1. 先固定相机，再固定黑纸，最后调整光源。
2. 调焦时以碎片边缘清晰为准，不要只看纸张边缘。
3. 让完整A4尽量占满画面，但四个角不能跑出画面。
4. 黑纸长边有67mm不在龙门架行程内，这是正常情况。竖放默认上下各舍弃33.5mm；横放默认左右各舍弃33.5mm。
5. 标定完成后，相机、镜头焦距、黑纸位置或分辨率只要有一个发生变化，就必须重新执行`AUTO ROI`和后续验收。

## 3. 安装和启动A版

1. 使用`maixcam2_app_A_quad/dist/diansai_quad-v1.10.0.zip`，不要误用稳定版或B版压缩包。
2. 在MaixVision中打开解压后的A版目录作为一个完整工程。
3. 确认`main.py`、`config.py`、`puzzle_vision.py`、`paper_locator.py`、`assembly_planner.py`、`calibration_ui.py`、`settings_store.py`、`template_store.py`、`touch_ui.py`位于同一工程中。
4. 运行`main.py`。程序正常启动后默认选择`UNKNOWN`的`WHITE`子模式并显示`PRESS START`，此时不会检测碎片。

如果出现`ModuleNotFoundError: No module named 'maixcam2_app_A_quad'`，通常是只上传了`main.py`、使用了旧包，或其他模块没有和`main.py`一起部署。重新解压v1.10.0并上传整个A版工程，不要只复制入口文件。

设备上的持久化文件如下：

| 文件 | 作用 |
|---|---|
| `/root/maixcam2_puzzle_A/vision_settings.json` | 保存A4四角、机械区域、分界线和视觉分割参数 |
| `/root/maixcam2_puzzle_A/known_templates.json` | 保存KNOWN模式的四片形状和正确目标布局 |

## 4. 屏幕界面速查

### 4.1 正常识别界面

| 按钮 | 作用 |
|---|---|
| `KNOWN` | 选择已登记模板K1～K4识别；点击后清除旧结果并回到`PRESS START`待机 |
| `UNKNOWN` | 选择不依赖模板的1～4片求解；点击后清除旧结果并回到待机 |
| `WHITE` / `CARD` | UNKNOWN下第三按钮显示当前材料；点击后切换材料、清除旧结果并回到待机，默认`WHITE` |
| `SAVE` | KNOWN且已经START后登记红线下方100×60mm四片；未START只提示`PRESS START` |
| `START` | 按当前模式和材料开始检测；再次点击会清空旧快照并从下一帧重新采集 |
| `CAL` | 进入调参界面；再次点击退出，保留模式选择但回到待机，必须重新START |

正常识别页和CAL页的画面范围不同：正常页已有ROI时只显示等比例A4纸面，纸外区域为纯黑；CAL页仍显示原始相机画面，便于观察完整A4四角、龙门架遮挡和AUTO ROI候选。正常页黄色框以内才是电机可达且允许进入规划的检测区域，完整A4显示范围不能替代黄色机械边界。

### 4.2 单次快照状态

| 状态 | 含义 | 下一步 |
|---|---|---|
| `PRESS START` | 当前模式已选择，但分割、稳定计数和求解器全部待机 | 确认模式/材料和摆放后点击START |
| `STABLE 1/3`、`2/3` | 正在比较实时轮廓，尚未锁定 | 保持碎片静止 |
| `LOCKED SOLVING ...` | 第3稳定帧已深复制，红点和求解坐标不会再变化 | 等待当前快照完成 |
| `LOCKED PLAN OK` | 当前快照已经得到目标 | 读取下半区放置位置 |
| `LOCKED PLAN 原因` | 当前快照失败或超时，程序不会自动换帧重试 | 调整碎片或参数后再次点击START重拍 |

KNOWN的`SAVE`是例外的即时锁定动作：四片已经在红线下方正确拼好时，先点击START取得当前检测，再点击SAVE直接登记并锁定当前帧；SAVE本身不再额外等待3帧，也不会启动UNKNOWN搜索。未START直接点击SAVE只显示`PRESS START`。

### 4.3 CAL调参界面顶部页签

| 页签 | 用途 | 重点看什么 |
|---|---|---|
| `ROI` | 查看完整A4和机械有效区域 | 蓝框是否贴合A4，黄框和红线位置是否正确 |
| `MASK` | 查看二值分割 | 白片是否完整变白，黑纸是否保持黑色 |
| `RESULT` / `MEASURE` | 第一次点RESULT看轮廓，再点一次切到量化页 | SCALE/GAP/STABLE/JITTER/RECT是否达到门槛 |
| `ADV` | 调整阈值、面积和形态学参数 | 状态能否达到`GOOD 4/4` |
| `CAL` | 退出调参界面 | 返回正常识别画面 |

### 4.4 ROI、MASK、RESULT页底部按钮

| 位置 | 显示 | 作用 |
|---:|---|---|
| 1 | `AUTO ROI` | 对当前帧自动查找完整黑色A4四角；每按一次只识别一次 |
| 2 | `-` | 当前机械参数减小0.5mm；选中`PAPER`时切换V/H |
| 3 | 当前参数和值 | 点击后按`X → Y → W → H → SPLIT → PAPER`循环选择；PAPER显示V或H |
| 4 | `+` | 当前机械参数增大0.5mm；选中`PAPER`时切换V/H |
| 5 | `LOCK ROI` | 保存A4四角、机械区域和分界线 |

### 4.5 ADV页底部按钮

| 位置 | 显示 | 作用 |
|---:|---|---|
| 1 | `PARAM:TH/MIN/OPEN/CLOSE` | 点击后循环选择调节项 |
| 2 | `-` | 减小当前参数 |
| 3 | 当前值 | TH项点击此按钮可在`AUTO`与`FIX`间切换 |
| 4 | `+` | 增大当前参数 |
| 5 | `SAVE` | 仅在`GOOD 4/4`时保存分割参数 |

### 4.6 MEASURE量化页

顶部只有一个`RESULT`页签：当前显示RESULT时再点一次会进入`MEASURE`，再点一次回到RESULT。只有MEASURE页执行距离变换和十帧稳定统计，其他页不会增加这部分计算量。

| 指标 | 测试摆放 | 合格标准 | 不合格首先处理 |
|---|---|---|---|
| `SCALE` | 蓝框锁定完整A4即可 | `≥2.00px/mm` | 完整部署1280×960分析版；让A4尽量占满画面并重新AUTO ROI |
| `GAP` | 放2～4片，最窄真实黑缝按比赛最小间距摆放 | `≥4.0px` | 对焦、均匀补光、保持`CLOSE=1`，再单独调整TH |
| `STABLE` | 1～4片和龙门架完全静止 | 连续达到`10/10 PASS` | 固定相机/纸张/光源，检查轮廓是否跳动 |
| `JITTER` | 与STABLE使用同一段10帧数据 | `≤1.00mm` | 修正焦距、反光、阈值和蓝框；中心不动但顶点跳动也会失败 |
| `RECT` | 清空其他碎片，只放一张实测100×60mm白色标准卡 | 长短边各自误差`≤1.5mm` | 先核对标准卡尺寸和蓝框，再考虑镜头畸变标定 |

GAP需要至少两片，RECT要求只有一片标准卡，因此两项应分两次摆放记录，出现`N/A`不等于失败。现场最终判定不是“某个参数看着顺眼”，而是SCALE、GAP、STABLE/JITTER和RECT四组测试分别达到上述门槛；若启动画面显示`RES LOW`，表示相机已回退640×480，必须重点复查SCALE和GAP，不能直接沿用高分辨率结论。

倾斜固定相机必须额外做五点RECT检查：把同一张真实100×60mm标准卡依次放在黄色机械区域的中心、左上、右上、右下、左下，每个位置保持完整、不触黄框并等待`10/10 PASS`后记录长短边。五处误差均应优先控制在1.5mm内，现场条件受限时也不应超过2mm。中心正确但四角系统性偏大或偏小，说明镜头径向畸变已经超过单一Homography的能力，不能通过修改TH、X/Y/W/H进行补偿；应先做镜头内参和畸变校正。碎片顶面明显高于黑纸时还会产生高度视差，应减小相机倾角，或让标定基准与碎片顶面处于同一高度。

## 5. 第一次完整标定流程

建议严格按以下顺序执行。这样能区分是纸张定位问题，还是碎片分割问题。

### 第一步：检查原始画面

1. 启动程序，确认画面方向正常、没有明显拖影。
2. 把4片碎片分开放在黑纸内，建议每片间隔至少5～10mm。
3. 不要让碎片压住A4纸边，也不要让龙门架压住纸的四个角。
4. 反复观察几秒：亮度不应随时间明显跳动，白片边缘应清楚。

### 第二步：自动查找完整A4

1. 点击`CAL`进入调参界面。
2. 进入`ROI`页。
3. 点击一次`AUTO ROI`。
4. 成功时会显示`AUTO ROI OK H xx%`或`AUTO ROI OK V xx%`；H表示A4长边水平，V表示长边竖直，蓝色/青色四边形应贴合完整A4纸边缘。
5. 失败时显示`AUTO ROI FAIL`。程序会保留上一次已保存的四角，不会用失败结果覆盖旧参数。

AUTO成功时程序会比较上/下两边平均像素长度与左/右两边平均像素长度，自动选择
`PAPER V`（竖放）或`PAPER H`（横放），并重置该方向的默认机械区。如果方向判断与
实物不一致，点击中间参数直到`PAPER`，再按`+`或`-`手动切换；最后必须重新按
`LOCK ROI`，方向才会随设置V5保存。

`AUTO ROI`优先在纸张边缘无遮挡时进行。黑纸内允许已有1～4片白色碎片，但白片不能越过纸边；第一次标定时，纸内只放1片通常更容易判断ROI是否正确。注意：完全空纸时可以自动找到A4，但`LOCK ROI`要求至少识别到1片完整碎片，因此锁定前需要放入1～4片碎片。

### 第三步：检查蓝框和毫米换算

A版不是用一个固定的“每像素多少毫米”比例直接换算，而是用蓝框四角建立完整A4的Homography透视映射。`PAPER V`使用210×297mm，`PAPER H`使用297×210mm。因此固定相机可以明显倾斜，画面不同位置的像素比例不同时，程序仍会先把全部碎片顶点反算到统一纸面毫米坐标，再进行拼装，最后把毫米目标正向映回画面。二维纸面任务不需要PnP；PnP也不能解决白片粘连、拼图组合、镜头径向畸变或高度视差。

蓝框合格标准：

| 检查位置 | 合格现象 | 不合格处理 |
|---|---|---|
| 左上、右上、右下、左下四角 | 蓝框顶点落在真实纸角 | 清理遮挡、压平纸角、改善照明后重按`AUTO ROI` |
| 四条边 | 蓝线沿黑纸外边界 | 排除画面中更大的黑色矩形或龙门架黑边 |
| 透视方向 | 蓝框与纸张形状一致，无交叉 | 重新定位纸张并重试 |

可用直尺做一次快速核对：在A4纸上放置两个相距100mm的明显标记或碎片中心，观察程序输出的毫米坐标差是否接近100mm。明显不符时应先修正蓝框，不能靠TH、MIN、OPEN或CLOSE补偿。

### 第四步：设置黄色机械有效区域

两种方向默认值如下：

| PAPER | X | Y | W | H | SPLIT |
|---|---:|---:|---:|---:|---:|
| `V`竖放 | 0.0 | 33.5 | 210.0 | 230.0 | 148.5 |
| `H`横放 | 33.5 | 0.0 | 230.0 | 210.0 | 105.0 |

操作方法：点击底部中间参数按钮选择`X/Y/W/H/SPLIT/PAPER`。机械值用`-`和`+`按0.5mm调整；PAPER用任一方向键切换V/H。红线在两种方向都保持水平，继续表示上半区和下半区。

约束如下：

- 黄色区域必须完整位于当前方向的A4毫米平面内部。
- V方向`W≤210、H≤230`；H方向`W≤230、H≤210`。
- `SPLIT`必须严格位于黄色区域内部。
- 参数到达边界后会显示`WORK LIMIT`，此时继续按相同方向不会变化。

如果黄色区域“只能缩小、不能增大”，先看当前方向和数值。默认值已经占满纸面与230mm行程的交集，不能再放大。竖放需要改变覆盖位置时调`Y`；横放时调`X`。若只是长宽被交换，不要硬调W/H，直接把`PAPER`切到正确方向。

### 第五步：在MASK页判断分割

进入`MASK`页，正确结果应满足：

| 画面对象 | 正确显示 |
|---|---|
| 黑纸背景 | 黑色，只有少量孤立噪点或完全无噪点 |
| 白色碎片 | 内部连续的白色区域 |
| 相邻碎片 | 中间黑缝清楚，没有粘成一块 |
| 黄框以外 | 不参与有效碎片识别 |

如果MASK已经不正确，不要先看RESULT。先按第6节调整ADV参数。

### 第六步：在RESULT页判断轮廓

| 颜色 | 含义 | 是否可用于规划 |
|---|---|---|
| 绿色 | 完整有效碎片 | 可以 |
| 橙色 | 轮廓触碰机械有效区边界，即`EDGE` | 不可以 |
| 红色 | 面积小于`MIN`，判为小轮廓 | 不可以 |
| 紫色 | 面积过大，可能是背景、反光或多片粘连 | 不可以 |
| 蓝色/青色框 | 完整A4纸边界 | 仅用于坐标换算 |
| 黄色框 | 机械有效区域 | 只识别该区域内的有效碎片 |
| 红线 | 上下区域分界线 | 线上方取料，线下方显示拼装目标 |

调试用4片都应显示为互相独立的绿色轮廓，且每片拟合为3～5个顶点。

### 第七步：锁定ROI

在ROI、MASK或RESULT页点击`LOCK ROI`。允许锁定的条件是：

- 已成功得到A4四角；
- 黑纸上识别到1～4片完整碎片；
- 有效轮廓数量为1～4；
- 没有`EDGE`轮廓；
- 没有面积过大的轮廓。

成功后应显示`ROI LOCKED`。如果显示`ROI NEEDS 1-4 COMPLETE`，先处理触边、粘连、漏检或背景轮廓，再重试。

### 第八步：保存ADV分割参数

1. 把4片调试碎片全部放在黄色区域内，互相分开且不触碰黄框或红线。
2. 进入`ADV`页，按第6节调节参数。
3. 状态必须达到`GOOD 4/4`。
4. 点击ADV页右下角`SAVE`，确认显示`ADV SAVED`。
5. 再点击顶部`CAL`返回正常界面。

`LOCK ROI`和ADV页`SAVE`是两个独立保存动作：前者只保存纸张及机械区域，后者只保存分割参数。只做其中一个并不等于完整标定。

### 第九步：重启验证

1. 停止并重新运行`main.py`。
2. 进入CAL，确认蓝框、黄框、红线仍位于原位置。
3. 检查ADV参数是否仍为已保存值。
4. 放入4片，确认仍能达到`GOOD 4/4`。

## 6. ADV参数怎么调

### 6.1 参数含义和步进

| 参数 | 默认值 | 调整范围/步进 | 增大后的主要效果 |
|---|---:|---|---|
| `TH` | `AUTO` | 固定模式0～255，每次5 | 只有更亮的像素保留为白色，噪声减少，但碎片可能变小或断裂 |
| `MIN` | 0.20% | 每次0.05%，显示为ROI面积比例 | 过滤更大的小噪声，但过大会漏掉小碎片 |
| `OPEN` | 3 | 1/3/5/7 | 去除小白点、细毛刺，但过大会侵蚀碎片 |
| `CLOSE` | 5 | 1/3/5/7/9 | 填补白片内部黑孔和小裂缝，但过大会把相邻碎片连接 |

TH参数中间值按钮的操作：

- 显示`AUTO:数值`时，当前使用Otsu自动阈值；`-`和`+`不会改变TH。
- 点击中间值后，程序用当前自动阈值进入`FIX:数值`模式。
- 固定模式下用`-`和`+`每次调整5。
- 再次点击中间值恢复AUTO模式。

### 6.2 推荐调节顺序

| 顺序 | 操作 | 通过标准 |
|---:|---|---|
| 1 | 先保持`TH=AUTO` | 大部分环境下白片与黑纸已经明显分开 |
| 2 | 调`MIN` | 小噪声消失，同时最小碎片仍保留 |
| 3 | 调`OPEN` | 孤立白点和边缘毛刺消失，碎片没有明显缩小 |
| 4 | 调`CLOSE` | 碎片内部孔洞闭合，相邻碎片仍不粘连 |
| 5 | AUTO仍不稳定时再固定`TH` | 连续观察10～20秒，轮廓数量和形状不跳变 |
| 6 | 最后到RESULT确认 | 4片全绿，状态`GOOD 4/4` |

### 6.3 按现象调参

| 现象 | 优先处理 | 调整方向 |
|---|---|---|
| 远处或小碎片漏检 | `TH`、`MIN`、`OPEN` | 固定TH后适当降低；降低MIN；减小OPEN |
| 白片内部出现黑洞 | `CLOSE`，其次TH | 增大CLOSE；必要时适当降低固定TH |
| 两片粘成一个轮廓 | 实物间距、`CLOSE` | 先拉开碎片，再减小CLOSE |
| 黑纸上有小白点 | `MIN`、`OPEN`、TH | 增大MIN或OPEN；必要时提高固定TH |
| 轮廓边缘毛刺多、顶点数跳动 | `OPEN`、照明、焦距 | 小幅增大OPEN；消除反光；重新调焦 |
| 碎片轮廓变得过小或断开 | `TH`、`OPEN` | 降低固定TH或减小OPEN |
| `EDGE` | 黄色区域或实物位置 | 调X/Y/W/H覆盖该片，或把碎片移离黄框边缘 |
| `BACKGROUND` | A4定位、TH、反光 | 检查蓝框和纸角；提高固定TH；消除大面积反光 |
| `NOISE` | `MIN`、`OPEN` | 增大MIN或OPEN，清理纸面杂物 |
| `MISS` | MASK、TH、MIN | 找出缺少的碎片，降低MIN并检查TH和焦距 |

每次只改一个参数，并在每次修改后等待画面稳定2～3秒。不要同时大幅改变TH、OPEN和CLOSE，否则无法判断是哪一个参数起作用。

## 7. 如何判断参数“真的调对了”

`GOOD 4/4`只是当前画面合格，不代表现场一定稳定。应做以下压力测试：

| 测试 | 操作 | 合格标准 |
|---|---|---|
| 位置测试 | 依次把最小碎片放到黄色区域四角和中心 | 均保持绿色，不出现EDGE或MISS |
| 旋转测试 | 每片分别旋转0°、约45°、90°和任意角 | 轮廓仍完整，顶点数稳定在3～5 |
| 数量测试 | 分别放1、2、3、4片 | 正常界面数量正确，无额外轮廓 |
| 间距测试 | 把两片逐渐靠近 | 在比赛允许的最小间距下仍为两个轮廓 |
| 光照测试 | 在预计现场亮度上下小幅变化 | AUTO或固定TH下识别不明显跳动 |
| 时间测试 | 保持4片静止30秒 | 不频繁出现MISS、NOISE、EDGE或BACKGROUND |
| 重启测试 | 设备断电重启 | ROI和ADV参数自动恢复 |

若固定TH只能在单一亮度下工作，而现场光线可能改变，应优先改善遮光和补光，再考虑继续使用AUTO。算法参数不能替代稳定的光学环境。

## 8. KNOWN模式调试

KNOWN模式适用于题目图2中形状固定、目标尺寸固定为100×60mm的四片碎片。v1.10.0的`SAVE`不再猜拼法：赛前先把四片按题图正确拼在红线下方，按`KNOWN → START → SAVE`同步验收联合矩形并登记K1～K4；正式运行时再把四片随机放在红线上方，点击START后最多比较24种模板分配并输出下半区目标。

### 8.1 首次自动登记

1. 确认ROI和ADV参数已经分别保存。
2. 在红线下方按题图把四片正确拼成100×60mm矩形，整体在纸面内旋转任意角度都可以。
3. 相邻片之间保留约1～2mm黑缝，四片都离红线和黄色边界至少5～10mm，且全部显示绿色完整轮廓。
4. 点击`KNOWN`，确认状态栏为`PRESS START`。
5. 点击`START`开始检测，确认状态栏中的`N=4`；额外的橙色EDGE轮廓不会计入N。
6. 点击正常界面的`SAVE`；同步登记通常在当前帧完成，不会进入UNKNOWN搜索，也不应长时间显示`SAVE SOLVING`。
7. 必须看到`KNOWN SAVED PLAN OK`，同时下半区出现目标外框、四片目标轮廓和箭头。

SAVE内部依次执行：筛选四片下半区完整轮廓、验证联合矩形尺寸/填充率/重叠率、规范到精确100×60mm、生成K1～K4模板、原子写入模板文件并装入规划缓存。流程固定最多24种模板分配，不创建UNKNOWN搜索任务；任何一步失败都不会覆盖上一次已保存模板。

常见SAVE状态：

| 状态 | 原因 | 处理 |
|---|---|---|
| `SAVE KNOWN_NEEDS_FOUR` | 完整可操作碎片不是4片 | 处理漏检、粘连、EDGE或多余轮廓，保持恰好四片绿色轮廓 |
| `SAVE KNOWN_LAYOUT_MUST_BE_LOWER` | 至少一片不完全位于红线下方 | 把正确拼好的四片整体移到下半区并离红线5～10mm |
| `SAVE KNOWN_LAYOUT_INVALID` | 联合外框尺寸、填充率、重叠率或毫米几何不合格 | 检查是否按题图正确拼装、黑缝是否过大、蓝框毫米标定是否准确 |
| `SAVE KNOWN_REGISTRATION_FAILED` | 几何验收通过但模板复核失败 | 检查四片轮廓顶点和形状稳定性后重新登记 |
| `SAVE TARGET_OUT_OF_WORK_REGION` | 红线下方机械范围放不下100×60mm目标 | 在机械允许范围内上移`SPLIT`或调整黄色区域 |
| `SAVE ERROR 类型` | 模板文件写入或其他运行异常 | 记录完整类型并重启复查；旧模板仍保留 |

### 8.2 保存后运行

首次SAVE成功后规划已缓存。正式测试或重启设备后，把同一套四片拆开并随机放在红线上方：连续稳定3帧后，程序匹配已保存K1～K4并显示精确100×60mm下半区目标。

程序使用碎片的**全部多边形顶点**判断区域，不是只看中心点：

| 区域值 | 判断条件 | KNOWN用途 |
|---|---|---|
| `region=upper` | 整片都在红线上方，并留出0.5mm判定余量 | 登记后正式运行时参与模板匹配 |
| `region=lower` | 整片都在红线下方，并留出0.5mm判定余量 | 仅首次正确布局SAVE时参与登记 |
| `region=crossing` | 任意一部分压到或跨过红线 | 不参与登记或运行规划 |

实机摆放时不要只留0.5mm，建议每片离红线至少5～10mm，避免轮廓抖动导致`upper/crossing`反复变化。

#### 专项诊断：`N=4`但下半区没有目标

如果屏幕显示：

```text
KNOWN N=4 EDGE=0 TH=... PLAN KNOWN_NEEDS_FOUR
```

v1.10.0中它表示当前没有四个可用于KNOWN运行规划的上半区碎片，或设备载入的模板不足四个：

- `N=4`不等于“上半区可规划碎片为4片”，它只说明识别层找到了4个完整轮廓。
- `N=4`只统计整张黄色区域中4个`complete=True`的完整轮廓，不区分上半区、下半区或跨线。
- KNOWN规划只使用`complete=True`且`region=upper`的碎片，并且设备中还必须已经保存4个KNOWN模板。
- `PLAN KNOWN_NEEDS_FOUR`表示“上半区可规划碎片不是4片”或“已保存模板不是4个”。
- 规划失败或尚未完成时，程序只画红色分界线，不画下半区目标。

按以下顺序处理：

1. 把4片全部移到红线上方，每片离红线和黄色边界至少5～10mm。
2. 确认4片都是绿色完整轮廓，状态保持`N=4`；跨线或位于下半区的完整片不会进入运行规划。
3. 若从未看到`KNOWN SAVED PLAN OK`，先在红线下方按题图正确拼成100×60mm，再按`KNOWN → START → SAVE`；不能在当前随机摆法直接保存。
4. 按屏幕上的`SAVE ...`具体原因查上表，登记成功后再拆开移回上半区验证。
5. 保存成功后立即检查下半区的紫色目标外框、彩色单片轮廓、橙色箭头和`R±角度`。

当前A版把目标直接叠加在相机画面的红线下半区，不会显示示例图那种独立黑底拼装示意窗口。两者表达的信息相同；如果需要完全相同的独立示意窗口，需要另外修改界面代码。

### 8.3 重启后的随机摆放验证

1. 把四片重新随机摆到红线上方，位置和角度均可任意。
2. 保证四片互不接触且都位于黄色区域内。
3. 点击`KNOWN`，再点击`START`。
4. 静止后观察`STABLE 1/3 → STABLE 2/3 → PLAN OK N=4`；已保存KNOWN模板只做最多24种匹配，通常不会停留在`SOLVING`。
5. 检查每片的橙色箭头、彩色目标轮廓、目标中心坐标和`R±角度`是否合理。

KNOWN运行时最多比较`4! = 24`种模板分配。v1.10.0会把每个闭合轮廓等弧长重采样为32点，所以小毛刺造成4/5顶点跳变时不会立刻清零；中心稳定容差为3mm，仍严格要求连续3帧。形状匹配阈值为1.60，允许约2mm边缘反光误差，但不允许镜像或明显异形。若仍显示`LOCKED PLAN KNOWN_MATCH_FAILED`，通常是蓝框方向/毫米换算不准、轮廓变化已经超过小毛刺、碎片翻面，或模板不是当前四片；处理后再次点击START重拍。

## 9. UNKNOWN模式调试

UNKNOWN模式支持1～4片、每片3～5边，尝试把碎片拼成约90×50mm至120×90mm的矩形目标。第三按钮用于显式选择材料，不能只看轮廓后让程序自动猜：

| 子模式 | 适用碎片 | 求解行为 |
|---|---|---|
| `WHITE` | 白纸覆膜、局部露铁、反光但没有需要连续匹配的印刷图案 | 找到第一个通过尺寸、填充和重叠硬条件的矩形立即结束，速度最快 |
| `CARD` | 扑克牌或其他必须比较接缝花纹的印刷碎片 | 找到首解后继续有限比较花纹；达到截止线时返回当前最优合法解 |

v1.10.0的UNKNOWN对每片同时保存两套几何。`outline_local`是从视觉完整轮廓得到的高保真闭合多边形，只负责实体重叠、矩形尺寸、填充率、机械中心和最终目标绘制；`hypotheses`是最多三个3～5边简化候选，只负责提出接缝和无缩放、无镜像的刚体位姿。机械中心始终由压缩前的完整轮廓计算；完整轮廓只有在面积保持率不低于99%、Douglas-Peucker偏差不超过0.75mm时才采用压缩结果，否则保留原始点，避免密集轮廓让单个几何工作单元出现O(N²)卡顿。

候选0优先，确实无解时才逐级开放候选1/2；同一布局中一片只能使用一个候选，不能从不同候选借边。同顶点数、边界距离在亚毫米范围内的相邻epsilon候选会合并为一类，不同顶点数不会互相合并，因此三个轻微抖动五边形不能挤掉接缝正确的四边形。这样反光产生的2～8mm伪边不会再迫使GRAPH、FOURFAST和FALLBACK使用三套互相矛盾的形状。

WHITE仍按三层顺序求解。第一层`GRAPH_AUTO`最多保留32条候选边并枚举90组连接关系；第二层仅在恰好四片且GRAPH无解时运行`FOUR_FAST`，按两片、三片、四片逐层保留最多32个父状态，并受2400工作单元和1.5秒CPU活动子预算限制；最后由`FALLBACK`继续使用同一锁定快照、同一完整轮廓和同一候选集合。三条路径的接缝位姿都由候选提出，所有重叠与最终硬验收都使用完整轮廓。CARD继续比较接缝花纹，但同样遵守双几何和候选一致性约束。`CLEAN`只为兼容旧日志保留调试预览，生产求解不再调用破坏性删点。

三层最终都执行同一机械硬验收：先要求填充率不低于92%、总重叠不超过3%且尺寸在题目范围；只有WHITE严格轮无解时，才允许填充率不低于86%，并额外要求每片至少一条边属于目标矩形外框。FOUR_FAST和WHITE FALLBACK的4%中间门预先计算“最终全部碎片总面积”，再用当前累计交叠估算最终联合面积；这样两片、三片阶段不会因为分母太小误删最终可通过3%硬门的正确路径。自交、退化或OpenCV异常轮廓会使用相同总面积口径回退MASK，而不是中断整个任务。

### 9.1 现场可调常量

下列值集中位于`assembly_planner.py`文件最前部的“现场调试常量”区域。下面行号对应v1.10.0源码；若以后增加文件头注释，以常量名搜索结果为准。修改后必须重新把完整A版工程部署到MaixCAM2，不能只改设备持久化JSON。

| 常量与位置 | 默认值 | 作用 | 现场调整原则 |
|---|---:|---|---|
| `UNKNOWN_STRICT_MIN_FILL_RATIO`，第14行 | `0.92` | 第一轮严格矩形最低填充率，WHITE、CARD和KNOWN登记共用严格逻辑 | 一般保持不动；提高会更严格，降低会增加错误拼法风险 |
| `UNKNOWN_RELAXED_MIN_FILL_RATIO`，第16行 | `0.86` | 仅WHITE严格填充不足时的第二轮最低填充率 | 轮廓正确但角点缺口导致`fill_reject`时可每次降低`0.01`；不建议低于`0.82` |
| `UNKNOWN_WHITE_SOLVER_MIN_EDGE_MM`，第19行 | `12.0` | 仅供旧`CLEAN`日志预览；生产求解不再按此值删除顶点 | 不用它修正求解结果；应调整下面五个候选宏 |
| `UNKNOWN_SHAPE_MAX_HYPOTHESES`，第20行 | `3` | 每片最多保留的接缝候选数 | 一般保持3；降到1会变快但更容易漏掉反光轮廓的正确简化形状 |
| `UNKNOWN_REAL_EDGE_MIN_MM`，第22行 | `20.0` | 题目真实边长基准，用于候选短边惩罚和诊断 | 与题目“真实边不短于20mm”一致，通常不要降低 |
| `UNKNOWN_EDGE_HARD_FLOOR_MM`，第24行 | `14.0` | 候选边硬下限；更短的边默认判为反光伪边 | 角点误差大但真实边被削短时可每次降低1mm；必须不大于20mm，过低会重新引入伪边 |
| `UNKNOWN_SHAPE_AREA_RETENTION_MIN`，第26行 | `0.96` | 简化候选相对完整轮廓必须保留的最小面积比例 | 候选全空且完整轮廓正确时可每次降低0.01；过低会接受削掉真实区域的候选 |
| `UNKNOWN_SHAPE_MAX_DEVIATION_MM`，第28行 | `3.0` | 候选边界与完整轮廓允许的最大双向偏差 | 露铁或反光凹口略深时可每次增加0.5mm；不要用大偏差掩盖粘连轮廓 |
| `UNKNOWN_FOUR_FAST_ENABLED`，第30行 | `True` | GRAPH失败后是否启用WHITE四片分层快路径 | 现场验证完成前保持True；改False可直接进入FALLBACK |
| `UNKNOWN_FOUR_FAST_BEAM_WIDTH`，第32行 | `32` | FOURFAST每层保留状态数 | 默认已覆盖本次现场正确路径；增大会提高特殊布局召回但变慢 |
| `UNKNOWN_FOUR_FAST_RELATION_LIMIT`，第34行 | `6` | 每个有向片对展开的最优接缝关系数 | 本次正确分段关系排名为2和5；不建议低于6 |
| `UNKNOWN_FOUR_FAST_MAX_WORK_UNITS`，第37行 | `2400` | 快路径候选检查硬上限 | 中间层触顶会转FALLBACK；完整层仍先验收已生成候选 |
| `UNKNOWN_FOUR_FAST_ACTIVE_BUDGET_SECONDS`，第39行 | `1.5` | 只累计四片FOURFAST真实CPU工作时间；到期后转FALLBACK | 建议保持1.0～2.0秒；不影响1～3片，也不要超过统一8秒预算 |
| `UNKNOWN_SOLVER_DEBUG`，第41行 | `True` | 输出一次性ROI、候选等级、三条路径和最终采用候选 | 调试完成后改为`False`；关闭后不构造明细字符串且不打印 |

容错门只解决白片覆盖不完整、反光或远距离角点造成的小缺口。若控制台显示毫米边长明显不对、两片已经粘成一个轮廓、目标尺寸超范围或重叠超过3%，不要继续降低`UNKNOWN_RELAXED_MIN_FILL_RATIO`，应先修正AUTO ROI、TH和形态学参数。

### 9.2 控制台日志怎么判断失败点

调试开关为`True`时，每次锁定只输出一次以下事件，不会每帧刷屏：

| 日志事件 | 关键字段 | 如何判断 |
|---|---|---|
| `[ROI] AUTO` | `result`、`orientation`、`confidence`、`threshold`、`edges_px` | H/V必须符合实物；四边长度用于发现错误候选和严重透视 |
| `[SOLVER] SNAPSHOT` | `mode`、`profile`、`count`、两个填充门 | 确认本次锁定材料模式和片数正确 |
| `[SOLVER] PIECE` | `center_mm`、`vertices_mm`、`edges_mm` | 核对毫米映射、错误角点、过短边和粘连轮廓 |
| `[SOLVER] SHAPE` | `candidates`、`best_vertices`、`min_edge`、`score` | 每片应有1～3个候选；`candidates=0`先处理候选硬门，不能增加求解超时；分数越小越优先 |
| `[SOLVER] CLEAN` | `vertices=A→B`、`removed`、`min_edge`、`cleaned_min` | 仅显示旧算法若执行删点会得到什么，便于对照历史日志；v1.10.0生产求解不使用此结果 |
| `[SOLVER] TIER` | `rank`、`edges`、`states`、`source` | `rank=0`只使用每片最佳候选；出现1/2表示已经实际展开次级候选，不代表修改完整轮廓；成功和失败阶段都会记录 |
| `[SOLVER] GRAPH` | `edges`、`sets`、`layouts`、`strict`、`relaxed`、拒绝数 | `layouts=0`通常是边匹配失败；`fill_reject`高说明候选有缺口；`outer_reject`说明容错拼法不满足每片外边 |
| `[SOLVER] FOUR_FAST` | `pairs`、`triples`、`complete`、`parents`、`units`、`limit`、`time_limit`、`active_ms`、`segmented`、`triangles`、`raster` | `limit=1`表示2400候选工作量触顶；`time_limit=1`表示1.5秒子预算到期，随后应看到FALLBACK，不是整个任务超时；`active_ms`只记录FOURFAST活动计算。四片成功时`result=OK`；`segmented>0`说明使用T形接缝；`raster`应远小于`triangles` |
| `[SOLVER] FALLBACK` | `nodes`、`frontier`、`first`、各类`reject` | 判断兜底是尺寸、填充、重叠还是边连接失败 |
| `[SOLVER] ACCEPT` | `shapes=U1:0,U2:1...`、`source` | 成功布局中每片最终采用的候选编号；编号只决定接缝位姿，机械中心和实体边界仍来自完整轮廓 |
| `[SOLVER] RESULT` | `source`、`success`、`reason`、`fill`、`overlap`、`outer`、`elapsed_ms` | 最终采用GRAPH还是兜底，以及实际验收裕量和耗时 |

排查时把同一次锁定从`SNAPSHOT`到`RESULT`的完整日志保存到电脑。先看`PIECE`确认毫米尺寸，再看`SHAPE`确认每片至少有一个合理候选，最后看`TIER`和各类拒绝数。`PIECE`毫米尺寸正确且候选合理，但`fill_reject`集中在86%～92%之间，才是调整容错门的典型场景；毫米尺寸本身错误时，先重做AUTO ROI和五点RECT。

不要靠继续增大8秒总计算预算或1.5秒FOURFAST预算掩盖错误轮廓。粘连、漏角、错误Homography或`SHAPE candidates=0`不会因为搜索更久自动变正确，只会让相同错误几何产生更多无效组合。只有日志显示候选正确、主要失败是搜索宽度或活动子预算触顶，并且硬门拒绝数没有持续指向尺寸/填充/重叠时，才考虑小幅调整搜索预算。

WHITE的GRAPH、FOUR_FAST和FALLBACK由同一个跨帧任务推进；CARD则在同一任务框架中直接进入原有纹理择优搜索。三阶段统一使用8秒累计计算预算，拍照、显示和帧间等待不计入；另有30秒总墙钟保护。只有四片FOURFAST额外受1.5秒活动子预算限制，1～3片从不进入该阶段，因此三片原有GRAPH→FALLBACK耗时不受影响。锁定后每帧默认最多给求解器24ms或64个工作单元，每检查一组GRAPH布局、一个FOURFAST候选或一个FALLBACK候选就可让出。GRAPH或FOURFAST失败事件输出后会结束当前帧，下一阶段从下一帧开始，因此该阶段日志不会混入后一阶段耗时。统一截止线到达时若已有合法解会直接返回当前最优解；没有首解则保留`LOCKED PLAN SOLVER_TIMEOUT`和当前快照，不再自动换一组抖动轮廓重试。

1. 把1～4片随机放在红线上方。
2. 每片必须完全位于黄色区域内，不跨红线、不互相接触。
3. 点击`UNKNOWN`。白色覆膜碎片确认第三按钮为`WHITE`；扑克牌则点击第三按钮切到`CARD`。每次切换后状态都应为`PRESS START`。
4. 点击`START`，再静止等待连续3帧稳定。第3帧后红点冻结并显示`LOCKED SOLVING`；WHITE统一任务先跨帧尝试`GRAPH_AUTO`，四片时再尝试`FOUR_FAST`，两条快路径都无解才在同一任务内继续FALLBACK。正常页在整个求解期间保持刷新，具体阶段以电脑日志为准。
5. 成功时显示`LOCKED PLAN OK N=片数`，目标矩形自动居中放到黄色区域下半部分。失败时先处理摆放或阈值，再次点击START采集新快照。

跨帧求解状态四项诊断用于判断“卡在哪里”：`N`为已深入节点数，`E`为边候选数，`F`为搜索过程中最大前沿宽度，`S=0`表示尚无合法矩形，`S=1`表示已经有可随时返回的合法解。WHITE若回退到旧搜索，应在`S`首次变成1时立即得到`PLAN OK`；CARD允许在`S=1`后继续短暂比较花纹。规划结果的内部诊断中，`graph_edge_candidates`、`graph_matching_sets`、`graph_layouts_checked`分别表示图路径实际采用的边数、连通组合数和硬验收布局数，`graph_fast_path=1`表示本次结果来自`GRAPH_AUTO`；前三项不会超过32、90、90。

| 状态 | 含义 | 处理 |
|---|---|---|
| `PLAN SHAPE_HYPOTHESIS_EMPTY` | 至少一片没有通过短边、面积保持和边界偏差硬门的候选 | 对照`SHAPE`逐片检查；先调14mm硬下限、96%面积保持或3mm偏差，不要增加超时 |
| `PLAN EDGE_GRAPH_EMPTY` | 候选存在，但没有任何长度和方向可兼容的接缝关系 | 检查Homography毫米长度、漏角、粘连和候选顶点数 |
| `PLAN LAYOUT_SIZE` | 搜索到完整组合，但外框不在90×50～120×90mm范围 | 核对蓝框、五点RECT和碎片是否漏检 |
| `PLAN LAYOUT_FILL` | 外框尺寸可行，但完整轮廓联合填充率低于92%/86% | 检查阈值削边、缺片和错误接缝；确认后才小幅调填充门 |
| `PLAN LAYOUT_OVERLAP` | 候选接缝形成了明显实体重叠，超过3%硬门 | 检查轮廓毛刺、错误候选和边匹配；3%门不得放宽 |
| `LOCKED PLAN SOLVER_TIMEOUT` | 8秒累计计算或30秒总墙钟到期且仍无首解；当前快照被保留 | 确认材料按钮，回RESULT处理错误顶点、粘连和噪声；调整后再点UNKNOWN重拍 |
| `PLAN TARGET_OUT_OF_WORK_REGION` | 红线下方空间放不下目标矩形 | 上移`SPLIT`或调整黄色区域，但必须符合机械实际范围 |
| `PLAN UNKNOWN_GEOMETRY_INVALID` | 碎片数量、顶点或毫米多边形无效 | 回到RESULT检查轮廓和蓝框 |

对白色无图案或局部反光碎片必须选`WHITE`，程序只按几何硬条件首解即停；对扑克牌等有图案碎片选`CARD`，才会加入边缘颜色和梯度连续性评分。扑克牌调试时应特别保证：

- 光源颜色稳定，避免自动白平衡反复变化；
- 牌面不过曝，红黑花色仍清楚；
- 焦距足以看清接缝附近图案；
- 先完成纯白片几何调试，再测试带图案碎片；
- 用多组随机角度实测，不能只验证一组摆法。

## 10. 规划画面的含义

| 图形/文字 | 含义 |
|---|---|
| 紫色目标外框 | 最终拼装矩形范围 |
| 彩色单片轮廓 | 每片碎片在目标矩形中的放置轮廓 |
| 橙色箭头 | 从当前碎片中心指向目标中心 |
| `(x,y)` | 目标中心，以完整A4左上角为原点，单位mm |
| `R+角度`或`R-角度` | 从当前姿态转到目标姿态所需的平面旋转增量，范围[-180°,180°) |

只有以下碎片会进入规划：

- `complete=True`，即完整绿色轮廓；
- 位于红线上半区；
- 数量为1～4片。

触碰黄框、跨红线、位于下半区或轮廓不完整的碎片不会进入规划。未点击START时相机只为屏幕提供实时纸面画面，不执行碎片分割、模板匹配、稳定计数或求解。START后碎片连续稳定3帧，程序深复制一次坐标和形状，求解期间及终态都只使用该快照；相机画面和触摸继续刷新，但正常页停止重复分割和轮廓提取，为组合搜索释放CPU。再次点击START会清除并重拍；切换KNOWN/UNKNOWN、切换材料或进出CAL会清除旧快照并回到`PRESS START`待机。

## 11. A4坐标到电机坐标

视觉输出的A4坐标定义为：

```text
A4左上角 = (0, 0)
X范围 = 0～210mm，向A4右侧增加
Y范围 = 0～297mm，向A4下侧增加
```

如果电机原点位于黄色区域左上角，且电机X、Y正方向与A4坐标相同，可先使用：

```text
motor_x = paper_x - work_x
motor_y = paper_y - work_y
```

默认`work_x=0.0mm`、`work_y=33.5mm`时：

```text
motor_x = paper_x
motor_y = paper_y - 33.5
```

若某一电机轴方向与视觉方向相反，对该轴使用反向公式。例如两轴都反向时：

```text
motor_x = work_width  - (paper_x - work_x)
motor_y = work_height - (paper_y - work_y)
```

旋转轴需要单独做正负方向标定。先选择一个不对称碎片，让程序输出约`R+30°`，命令机械空载旋转小角度，确认实际方向；若相反，则下位机使用`motor_r = -vision_r`。最终还要补偿夹具中心相对相机识别中心的机械偏置。

### 电机联调安全顺序

| 阶段 | 动作 | 合格标准 |
|---:|---|---|
| 1 | 只显示目标，不驱动电机 | 屏幕箭头和目标轮廓肉眼合理 |
| 2 | 夹具抬高，发送单点坐标 | 龙门架移动方向和距离正确 |
| 3 | 用纸上四个已知点检查 | 四角误差方向一致，无轴交换或反向 |
| 4 | 加入旋转轴，小角度测试 | R正负方向和角度一致 |
| 5 | 低速抓取单片 | 落点中心和旋转正确 |
| 6 | 再测试四片完整流程 | 无越界、碰撞和累计误差 |

## 12. 现场故障决策流程

现场不要一看到识别错误就同时修改所有参数。按下列数据流从左到右检查，前一层不合格时先不要检查后一层：

```text
原始画面 → A4定位 → MASK分割 → RESULT轮廓 → 上下区分类 → KNOWN模板 → 拼装规划 → 目标绘制
```

### 12.1 八层定位顺序

| 层级 | 在哪里看 | 通过标准 | 不通过时做什么 |
|---:|---|---|---|
| 1. 原始画面 | ROI页未叠加区域 | A4四角可见、碎片边缘清楚、亮度不跳变 | 固定相机和纸张，调焦，消除反光和遮挡 |
| 2. A4定位 | ROI页蓝框 | 蓝框贴合完整A4四边，黄框位于真实机械范围 | 重按`AUTO ROI`，再调X/Y/W/H/SPLIT并`LOCK ROI` |
| 3. 二值分割 | MASK页 | 每片是一个独立连续白块，黑纸和片间缝隙为黑色 | 依次调TH、OPEN、CLOSE，不先调MIN |
| 4. 轮廓分类 | RESULT页 | 目标碎片均为绿色，无多余橙/红/紫轮廓 | 根据EDGE/SMALL/LARGE分别处理 |
| 5. 上下区分类 | 正常页红线和碎片位置 | 待搬运碎片全部位于红线上方且不压线 | 把整片移离红线5～10mm |
| 6. KNOWN模板 | KNOWN保存状态 | 明确出现过`KNOWN SAVED PLAN OK` | 在下半区按题图正确拼成100×60mm后重新点击SAVE |
| 7. 拼装规划 | 正常页状态栏 | 依次出现稳定计数并最终显示`PLAN OK N=...` | 按PLAN失败文字查表，不重复乱按SAVE |
| 8. 目标绘制 | 正常页下半区 | 出现紫色外框、彩色单片轮廓、箭头和位姿 | 先确认PLAN成功；失败计划只画红线 |

### 12.2 常见现象与最小调试动作

| 现象/状态 | 根因定位 | 先看哪个页面 | 只做的第一项调整 | 调整后的合格标准 |
|---|---|---|---|---|
| `PRESS START`且没有碎片轮廓 | 当前处于v1.10.0完全待机，不是漏检 | 正常页 | 确认KNOWN/UNKNOWN和WHITE/CARD后点击START | 出现实时轮廓和`STABLE 1/3` |
| `AUTO ROI FAIL` | 没有找到可靠A4四边形 | ROI | 清除四角遮挡并让完整纸边进入画面，然后重按一次AUTO ROI | `AUTO ROI OK H/V xx%`且方向正确、蓝框贴边 |
| AUTO ROI成功但黄框不在机械范围 | A4四角正确，机械毫米区域参数不合适 | ROI | 选择X/Y/W/H/SPLIT，每次调0.5mm | 黄框对应真实210×230mm范围，红线位置正确 |
| 两片距离看着足够仍然粘连 | 高分辨率MASK中的黑缝像素太少，CLOSE或阈值形成白色连接桥 | MEASURE、MASK | 先确认`SCALE≥2px/mm`和`GAP≥4px`；默认保持`CLOSE=1`，再单独调TH | 两片之间出现连续黑缝并形成两个白块 |
| `CLOSE=1`仍然粘连 | 固定阈值过低、焦点不清或反光已经把黑缝变白 | MASK | 先改善焦距/光照；再把TH从AUTO锁成FIX后提高5，逐次观察 | 黑缝出现，同时碎片不变细、不破裂 |
| 白片内部有黑洞 | CLOSE不足或固定TH过高 | MASK | CLOSE增大一级 | 白片内部连续，相邻碎片仍分开 |
| `SMALL`增加、某片不进入N | 轮廓面积小于MIN，或碎片被阈值切碎 | MASK后看RESULT | 先确认MASK完整；完整时把MIN每次降低0.05% | 小碎片变绿，纸面噪声没有大量进入 |
| `MISS`或N少于实物数量 | 漏分割、面积过滤或顶点异常 | MASK、RESULT | 找到缺失片；按MASK现象只改TH或MIN中的一个 | 实物数量与绿色轮廓数量一致 |
| `NOISE`或N多于实物数量 | 反光、纸面杂物或MIN太低 | MASK、RESULT | 清理反光杂物；仍有小点再提高MIN 0.05% | 多余轮廓消失，最小真碎片仍保留 |
| `EDGE` | 有效轮廓距离黄色四边形不超过2像素边缘余量 | RESULT | 把对应碎片向黄框内部移动5～10mm | `EDGE=0`且轮廓变绿 |
| `LARGE`或`BACKGROUND` | 大面积亮背景进入黄框、纸面反光或碎片粘成大块 | MASK、RESULT | 先检查蓝框/黄框是否越出黑纸，再消除反光 | 黄框内背景为黑，无紫色大轮廓 |
| `STABLE 1/3`反复重置 | 轮廓位置变化超过稳定容差，或识别抖动 | RESULT、正常页 | 保持碎片和龙门架静止，观察轮廓是否跳动 | 连续进入`STABLE 2/3`并完成规划 |
| WHITE四片稳定后经过短暂`SOLVING`出现`PLAN OK` | `GRAPH_AUTO`或`FOUR_FAST`找到硬验收合格矩形 | 正常页、控制台 | 看`RESULT source=GRAPH/FOUR_FAST`；核对目标尺寸、箭头和角度 | 目标与实物拼法一致，且输出位于下半区 |
| `SOLVING N/E/F/S`但画面仍刷新 | 正在按帧推进拼装搜索，这是正常状态 | 正常页 | WHITE关注S是否从0变1；CARD允许S=1后继续短暂择优 | 出现`PLAN OK`或具体失败原因 |
| 四片FOURFAST约1.5秒后仍无解 | 快路径活动子预算已到，或某个底层几何调用尚未返回 | 控制台、RESULT | 查看`FOUR_FAST time_limit/active_ms`；`time_limit=1`后应明确进入FALLBACK，若单个工作单元长期不返回则保存完整日志 | 正常情况是FOURFAST成功，或输出`time_limit=1`后继续FALLBACK |
| 四片总求解超过5秒仍没有结果 | FOURFAST已经让出，但FALLBACK仍在大量错误边和轮廓候选中搜索 | 控制台、RESULT | 先确认FOURFAST已有结束日志，再看FALLBACK的`nodes/fill_reject/overlap_reject`；修复自交角点和错误短边，不要盲目增大1.5秒子预算 | 在统一8秒活动预算内得到PLAN，或输出明确失败原因 |
| 显示`LOCKED SOLVING`后画面和触摸同时停止超过2秒 | 可能运行旧包，或当前单个底层工作单元异常慢 | 启动工程和版本 | 重新部署完整v1.10.0 ZIP；若仍复现，保存串口日志和当时画面 | 正常候选间画面持续刷新，工作单元返回后按预算结束或输出当前最优解 |
| `N=4`但`PLAN KNOWN_NEEDS_FOUR` | 上半区有效片不足4，或模板数量不是4 | 正常页 | 若未登记，先在下半区正确拼好并SAVE；已登记则把四片拆开全部放上半区 | `KNOWN SAVED PLAN OK`后随机摆放得到`PLAN OK N=4` |
| 点击SAVE后下半区没有目标 | 正确布局验收或文件保存失败 | 正常页 | 读取完整`SAVE ...`状态，重点区分`KNOWN_LAYOUT_MUST_BE_LOWER`和`KNOWN_LAYOUT_INVALID` | 保存成功状态与目标同时出现 |
| `PLAN KNOWN_MATCH_FAILED` | 当前轮廓与已保存模板差异过大 | RESULT | 核对蓝框和轮廓；必要时用当前实物重新登记KNOWN布局 | 四片得到K编号并规划成功 |
| `PLAN KNOWN_POSE_FAILED` | 模板匹配成功，但某片当前轮廓无法稳定配准到目标姿态 | RESULT | 检查该片顶点拟合和轮廓抖动，仍失败时重新登记当前实物 | 四片均显示合理目标角度并规划成功 |
| `PLAN TEMPLATE_NO_LAYOUT`或`TEMPLATE_LAYOUT_INVALID` | 模板文件缺少目标布局或内容无效 | 正常页 | 在下半区按题图正确拼好四片后重新SAVE | 不再出现模板布局错误 |
| `PLAN SHAPE_HYPOTHESIS_EMPTY` | 至少一片没有合格接缝候选 | RESULT、控制台 | 按`SHAPE`定位该片，检查伪短边、面积保持和边界偏差 | 每片`candidates=1～3` |
| `PLAN EDGE_GRAPH_EMPTY` | 候选存在但没有兼容接缝关系 | RESULT、控制台 | 检查缺片、粘连、顶点数和蓝框毫米标定 | `GRAPH edges>0`并继续布局检查 |
| `PLAN LAYOUT_SIZE` | 完整轮廓组合外框尺寸不合格 | ROI、RESULT | 核对蓝框、五点RECT与碎片毫米尺寸 | 外框进入90×50～120×90mm范围 |
| `PLAN LAYOUT_FILL` | 矩形内部缺口过大 | MASK、RESULT | 检查阈值削边、缺片和错误接缝 | 完整轮廓填充率达到92%或WHITE容错86% |
| `PLAN LAYOUT_OVERLAP` | 候选位姿造成碎片实体重叠 | RESULT | 检查完整轮廓毛刺、错误候选和接缝匹配 | 重叠率不超过3% |
| `LOCKED PLAN SOLVER_TIMEOUT` | 8秒累计计算或30秒硬墙钟到期时仍没有合法矩形 | RESULT、材料按钮 | 确认WHITE/CARD并处理粘连、错误顶点和噪声，再点UNKNOWN | 回到STABLE并锁定一份新的正确轮廓 |
| `PLAN SOLVER_ERROR` | 某个增量几何或OpenCV工作单元发生异常 | 正常页、串口日志 | 记录当时画面与完整状态，切换模式后重试；重复出现则保存复现图 | 不退出主循环，并能重新进入STABLE/SOLVING |
| `PLAN TARGET_OUT_OF_WORK_REGION` | 红线下方放不下目标矩形 | ROI | 在机械允许范围内上移SPLIT | 下半区高度足够且目标完整位于黄框内 |
| 已显示`PLAN OK`但看不见目标 | 需要核对画面叠加或目标颜色，不再是求解失败 | 正常页 | 确认紫色外框是否被碎片/文字遮住，并保存一张完整截图 | 紫框、单片轮廓、箭头和位姿至少可见一项 |

### 12.3 一次只改一项

每轮调试只改变一个变量，并至少观察2～3秒。建议按下面格式记录：

| 轮次 | 页面 | 修改前完整状态 | 只修改的参数/摆放 | 修改后完整状态 | 结论 |
|---:|---|---|---|---|---|
| 1 | MASK |  | 例如CLOSE 5→3 |  | 黑缝是否出现 |
| 2 | RESULT |  | 例如MIN 0.20%→0.15% |  | SMALL是否减少 |

禁止在同一轮同时修改TH、MIN、OPEN和CLOSE。否则即使结果变好，也无法确定真正起作用的变量，换场地后很难复现。

## 13. 状态文字故障表

| 状态 | 含义 | 立即检查 |
|---|---|---|
| `PRESS START` | 正常页完全待机，不执行碎片分析 | 选择模式和材料后点击START；若要重拍也点击START |
| `AUTO ROI OK H/V xx%` | 本次找到A4四角并给出横/竖方向 | 先核对H/V是否符合实物，再看蓝框是否贴纸边；置信度不是唯一标准 |
| `AUTO ROI FAIL` | 本次没有可靠A4候选 | 四角遮挡、反光、纸边出画、背景有大黑矩形；旧ROI仍保留 |
| `WORK LIMIT` | X/Y/W/H/SPLIT已到合法边界 | 切换参数或反方向调整 |
| `ROI NEEDS 1-4 COMPLETE` | 当前不满足ROI锁定门槛 | 保证1～4片完整且无EDGE/LARGE |
| `ROI LOCKED` | 纸张和机械区域已保存 | 继续保存ADV参数并重启复查 |
| `GOOD 4/4` | 当前4片分割全部合格 | 点击ADV页`SAVE` |
| `NEED GOOD 4/4` | ADV保存门槛未达到 | 根据EDGE/SMALL/LARGE和MASK处理 |
| `ADV SAVED` | 分割参数已保存 | 退出CAL并重启验证 |
| `BACKGROUND` | 大轮廓或白色占比异常高 | 蓝框、反光、TH、龙门架或亮背景 |
| `EDGE` | 有轮廓触碰黄框 | 移动物体或调整机械区域 |
| `MISS` | 少于4片完整有效轮廓或顶点异常 | TH、MIN、OPEN、焦距和遮挡 |
| `NOISE` | 有效轮廓多于4个 | MIN、OPEN、纸面杂物和反光 |
| `STABLE 1/3`、`2/3` | 正在等待连续稳定帧 | 保持碎片静止，不要遮挡画面 |
| WHITE经过短暂`LOCKED SOLVING`到`PLAN OK` | 统一跨帧任务中的`GRAPH_AUTO`或四片`FOUR_FAST`已经成功，没有进入FALLBACK | 看控制台`RESULT source`并核对紫框、单片轮廓、箭头和角度 |
| `SOLVING N=... E=... F=... S=...` | UNKNOWN正在跨帧搜索；S=1表示已有可返回首解 | WHITE在S=1立即结束；CARD可继续短暂择优；画面持续刷新表示正常 |
| `SAVE SOLVING N=...` | 仅旧兼容接口可能出现；v1.10.0实机KNOWN SAVE不进入UNKNOWN搜索 | 确认部署的是完整v1.10.0包；不要混用旧main.py或assembly_planner.py |
| `PLAN OK N=...` | 已生成并缓存N片目标位姿 | 核对箭头、坐标和角度 |
| `NO TEMPLATE` | KNOWN模板不存在 | 在红线下方按题图正确拼成100×60mm后点击SAVE |
| `KNOWN SAVED PLAN OK` | 下半区正确布局验收、模板保存和即时规划均成功 | 拆开四片并随机移到上半区验证KNOWN匹配 |
| `SAVE KNOWN_NEEDS_FOUR` | SAVE看到的完整可操作轮廓不是四片 | 处理漏检、粘连、EDGE和多余轮廓，保持恰好四片 |
| `SAVE KNOWN_LAYOUT_MUST_BE_LOWER` | SAVE时至少一片不完全位于红线下方 | 把正确拼好的四片整体放入下半区并留边界余量 |
| `SAVE KNOWN_LAYOUT_INVALID` | 正确布局的尺寸、填充、重叠或毫米几何验收失败 | 核对题图拼法、1～2mm黑缝、蓝框和MEASURE指标 |
| `PLAN KNOWN_NEEDS_FOUR` | 上半区有效碎片或KNOWN模板不是4个 | 已登记时把拆开的四片全部移到红线上方；未登记时先做下半区SAVE |
| `PLAN KNOWN_MATCH_FAILED` | 当前四片与模板匹配失败 | 检查ROI和轮廓稳定性，必要时重新登记当前实物 |
| `PLAN KNOWN_POSE_FAILED` | 已匹配碎片无法计算可靠目标旋转位姿 | 检查顶点拟合和轮廓稳定性，必要时重新登记模板 |
| `PLAN TEMPLATE_NO_LAYOUT` | 模板没有正确布局字段 | 在下半区按题图正确拼好四片后重新SAVE |
| `PLAN TEMPLATE_LAYOUT_INVALID` | 已保存布局尺寸或内容损坏 | 重新登记并覆盖模板文件 |
| `PLAN UNKNOWN_PIECE_COUNT` | UNKNOWN可规划碎片数量不在1～4 | 调整碎片位置和识别参数 |
| `PLAN UNKNOWN_GEOMETRY_INVALID` | UNKNOWN轮廓毫米几何无效 | 回到RESULT检查顶点、蓝框和触边情况 |
| `PLAN SHAPE_HYPOTHESIS_EMPTY` | 至少一片没有通过质量门的接缝候选 | 看`SHAPE`并调整14mm硬下限、96%面积保持或3mm偏差 |
| `PLAN EDGE_GRAPH_EMPTY` | 合格候选之间没有兼容接缝 | 检查顶点数、缺角、粘连和毫米标定 |
| `PLAN LAYOUT_SIZE` | 完整轮廓组合外框尺寸不合格 | 核对蓝框、五点RECT及碎片实际尺寸 |
| `PLAN LAYOUT_FILL` | 完整轮廓矩形内部缺口过大 | 检查缺片、阈值削边和错误接缝 |
| `PLAN LAYOUT_OVERLAP` | 候选位姿使完整轮廓实体重叠 | 检查轮廓毛刺、候选等级和边匹配 |
| `LOCKED PLAN SOLVER_TIMEOUT` | 8秒累计计算或30秒硬墙钟到期且S始终为0 | 确认材料模式并回RESULT处理轮廓，再点UNKNOWN重新采集 |
| `PLAN SOLVER_ERROR` | 增量求解内部异常已被安全拦截 | 记录画面和串口信息，切换模式后重试；重复出现时保留复现图 |
| `PLAN TARGET_OUT_OF_WORK_REGION` | 下半区空间放不下目标 | 在机械允许范围内上移SPLIT |
| `CAL ERROR 类型` | 某次调参动作发生异常 | 记录完整文字和复现步骤，不要反复覆盖参数 |

## 14. 分阶段验收清单

### 14.1 视觉验收

- [ ] 相机、焦距、黑纸和光源已固定。
- [ ] 完整A4四角均在画面内。
- [ ] `AUTO ROI`成功，蓝框四边贴合纸边。
- [ ] PAPER V/H与实际摆放一致；黄色区域覆盖对应210×230mm或230×210mm运动区。
- [ ] 红线与实际上下区域分界一致。
- [ ] 4片在黄框不同位置都能显示绿色轮廓。
- [ ] 4片任意旋转后仍识别为3～5边。
- [ ] `GOOD 4/4`能够连续保持，而不是偶尔闪现。
- [ ] 已分别看到`ROI LOCKED`和`ADV SAVED`。
- [ ] 重启后参数恢复。

### 14.2 拼装规划验收

- [ ] 未点击START时显示`PRESS START`且没有碎片轮廓、STABLE或SOLVING状态。
- [ ] KNOWN四片先在红线下方按题图正确拼成100×60mm，按`KNOWN → START → SAVE`后显示`KNOWN SAVED PLAN OK`。
- [ ] KNOWN随机摆放后点击START，显示`PLAN OK N=4`。
- [ ] UNKNOWN用1、2、3、4片分别测试。
- [ ] 白色覆膜碎片选择WHITE，首解后立即得到PLAN OK；扑克牌选择CARD并验证花纹择优。
- [ ] 求解时能看到`N/E/F/S`，无首解超时后保持当前失败快照；再次点击START才重拍。
- [ ] 目标矩形始终位于黄框下半区。
- [ ] 每片箭头起点、目标中心和旋转角肉眼合理。
- [ ] 碎片跨红线或触黄框时不会被错误加入规划。

### 14.3 比赛现场最终检查

- [ ] 使用的是A版v1.10.0，不是历史包或B版。
- [ ] 龙门架停在标定时的固定停车位。
- [ ] A4纸没有移动、卷边或被遮挡。
- [ ] 倾斜相机已经用100×60mm标准卡完成中心加四角五点RECT检查，五处误差均不超过2mm。
- [ ] 光照与标定时接近，无明显反光。
- [ ] 先用4片快速确认RESULT全绿。
- [ ] 正常界面能稳定出现`PLAN OK`。
- [ ] 电机原点、X/Y方向和旋转正负已确认。
- [ ] 正式抓取前完成一次低速空载运行。

## 15. 调试记录表

每次改变相机位置、光源或参数时复制一行记录。不要只记“能识别”，应记录测试条件和失败位置。

| 日期/场地 | 相机高度 | 光照条件 | PAPER与X/Y/W/H/SPLIT(mm) | TH | MIN | OPEN | CLOSE | GOOD保持时间 | 四角测试 | KNOWN结果 | UNKNOWN结果 | 备注 |
|---|---:|---|---|---|---:|---:|---:|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |

出现问题时至少保存以下信息：

1. ROI、MASK、RESULT、ADV四个页面的照片。
2. 屏幕完整状态文字，例如`EDGE 1`或`PLAN LAYOUT_FILL`。
3. 当时的TH、MIN、OPEN、CLOSE值。
4. 碎片数量、位置、角度和是否有反光。
5. 相机或黑纸是否刚刚移动过。

按这五项记录，后续可以明确区分纸张定位、二值分割、轮廓拟合、拼装求解和机械坐标中的哪一层出了问题。
