# UNKNOWN 四片专用识别与求解链路设计

## 1. 背景与目标

当前 A 版在 UNKNOWN 两片、三片场景中已有可用的识别和求解链路，但四片随机拼图仍可能受到轮廓抖动、透视畸变、白纸反光、碎片粘连和通用搜索超时影响。

本次改造的目标是新增一条完全独立的 UNKNOWN 四片链路：

```text
A4 蓝框标定
→ 完整纸面透视展开
→ HSV/LAB 联合提取白色碎片
→ 提取轮廓、边线和重心
→ 四片专用图搜索
→ 显示并通过 UART4 一次发送全部结果
```

四片改造不得改变 KNOWN 以及 UNKNOWN 一至三片的识别速度、求解结果和协议格式。

## 3. 用户交互与路径隔离

UNKNOWN 页面新增明确的 `FOUR` 模式按钮。用户放置四片时主动选择 FOUR，然后点击 START。

不能仅依赖“当前检测到了四个轮廓”自动进入四片路径。四片中的两个轮廓如果暂时粘连，画面只会产生三个连通区域，自动计数会错误进入三片算法。

路径隔离如下：

```text
模式选择
├── KNOWN：保留当前路径
├── UNKNOWN 1/2/3：保留当前识别和 GRAPH/FALLBACK 路径
└── UNKNOWN FOUR：进入新的透视视觉前端和四片专用求解器
```

四片链路不复用 KNOWN 模板，也不进入当前通用 FALLBACK。

## 4. 模块边界

| 模块 | 职责 | 约束 |
|---|---|---|
| `main.py` | 增加 FOUR 模式、状态分流、画面和按键处理 | 不在主循环内实现复杂视觉或求解逻辑 |
| `four_piece_vision.py` | 完整 A4 透视展开、双阈值分割、轮廓恢复、稳定锁定、几何提取 | 仅 FOUR 模式调用 |
| `four_piece_solver.py` | 边线匹配、候选连接图、分层组合、矩形验收和目标布局 | 不依赖 KNOWN 模板和旧 FALLBACK |
| `assembly_planner.py` | 保留 KNOWN 和 UNKNOWN 一至三片现有算法 | 用户现场宏不得被四片参数覆盖 |
| `serial_protocol.py` | 继续编码现有拼图结果帧 | 协议格式和 F4 解析方式不变 |

四片专用宏使用 `FOUR_` 前缀，避免与现有 UNKNOWN 参数互相影响。

## 5. 状态机

```text
IDLE
  │ 点击 START
  ↓
DETECTING
  │ 连续三帧得到稳定的四个轮廓
  ↓
LOCKED
  │ 冻结轮廓、重心和边线
  ↓
SOLVING
  ├── 成功 → PLAN OK → 显示并发送一次结果
  └── 失败 → PLAN FAIL → 保留诊断画面，等待手动重试
```

具体约束：

- 点击 START 前完全待机。
- 锁定后停止重复识别，求解期间不使用后续相机帧更新角点。
- 失败后禁止自动循环重拍和重算。
- 只有再次点击 START/RETRY 才清除快照并开始新任务。
- 每个成功任务只允许发送一次拼图结果帧。

## 6. A4 透视展开与坐标系

视觉前端读取已保存的蓝框四角，建立原相机图到完整 A4 纸面的 Homography。

- 竖放纸面：`210mm × 297mm`
- 横放纸面：`297mm × 210mm`
- 默认展开比例：`FOUR_WARP_PIXELS_PER_MM = 3.0`
- 竖放展开图约为 `630 × 891` 像素
- 横放展开图约为 `891 × 630` 像素

普通模式从原图提取轮廓后将点变换到纸面毫米坐标；四片模式先展开图像，再按固定比例将展开图坐标转换成纸面毫米坐标。两条路径最终使用同一坐标原点、轴方向和单位。

屏幕显示坐标与机械毫米坐标分开管理。正常页按CAL中蓝框的实际横竖外观展开，
侧装相机看到横纸时保持横向显示；求解、上下区和UART仍按固定安装方向定义的
逻辑纸面坐标运行。FOUR调试掩膜在覆盖正常页前按二者的四角循环位移旋转。

在标定准确且分割一致时，两种路径在数学上等价。现场允许源中心有约 `0.5～2mm` 的分割差异；持续超过 `3～5mm` 应检查蓝框四角顺序、横竖方向或标定精度。

## 7. HSV/LAB 双阈值白片分割

单一 HSV 阈值容易受到铁片露出、白纸阴影和局部反光影响。四片视觉前端使用两级掩膜：

1. 严格核心掩膜：HSV 低饱和、高亮度，同时参考 LAB 亮度，优先保证碎片之间的黑缝不被连接。
2. 宽松支撑掩膜：适当放宽亮度和饱和度，用于补回同一碎片内部的阴影、铁片和反光区域。
3. 区域恢复：从严格核心向宽松支撑区域生长，仅恢复与该核心连通的部分。

形态学限制：

- 禁止对整张掩膜进行可能跨越黑缝的膨胀和大闭运算。
- 仅删除面积很小的孤立噪点。
- 仅填补单片内部的小孔。
- 几何轮廓最终从恢复后的单片区域提取。

主要现场宏包括：

```python
FOUR_WARP_PIXELS_PER_MM
FOUR_HSV_S_MAX
FOUR_HSV_V_MIN
FOUR_LAB_L_MIN
FOUR_STABLE_FRAMES
FOUR_CENTER_JITTER_MM
FOUR_AREA_JITTER_RATIO
FOUR_SPLIT_CONNECTED_ENABLED
```

## 8. 轮廓计数、粘连处理与稳定锁定

FOUR 模式明确期望四片，因此轮廓计数不会触发一至三片求解器。

- 恰好四个有效区域：进入跨帧稳定判断。
- 三个有效区域：检查异常大区域中的黑色缝隙、轮廓凹陷和严格核心数量，最多尝试一次受限拆分。
- 五个及以上区域：按面积、核心支持率和轮廓质量过滤小噪点；仍不为四个时报告失败。
- 其他数量：显示实际计数并继续检测，直到超时或用户取消。

受限拆分不得仅为了凑够数量而任意切割。拆分结果必须满足面积下限、两侧都有严格白色核心、切口附近存在黑缝或明显凹陷。

连续三帧同时满足以下条件后锁定：

- 均得到四个有效轮廓；
- 通过最小代价匹配能够对应到同一组碎片；
- 各碎片重心位移不超过毫米阈值；
- 各碎片面积变化率不超过阈值。

锁定时冻结展开图、掩膜、原始轮廓、重心和几何候选。

## 9. 边线与形状假设

每片保留原始掩膜轮廓，并通过多个简化尺度生成少量形状假设。这样既避免单次 `approxPolyDP` 受反光伪角影响，也限制组合数量。

- 合并明显短于真实结构尺度的伪短边。
- 对近共线边进行受角度和距离约束的合并。
- 长边使用直线拟合提高方向稳定性。
- 重心使用纸面矫正图中的区域矩计算。
- 每个假设记录面积误差、轮廓拟合误差、最短边和自交状态。
- 每片只保留评分最好的少量假设。

求解始终使用轮廓和边线，不使用 KNOWN 模板标签。

## 10. 四片专用图搜索

求解器先计算有向片对之间的候选接缝，再按两片、三片、四片逐层组合。

实机回放发现，含五边形反光伪角的轮廓可能让“每个锚点单独占关系名额”的原生图
提前丢失正确分段边。最终实现因此在FOUR内部保留两个互补的增量图核心：

- 四片都为干净三角形/四边形：优先使用原生形状假设图，保持规则布局速度与结果。
- 任一简化轮廓超过四个顶点：优先使用已通过实机快照的边长守恒/外框紧凑度快图。
- 首个核心无解才运行另一个核心；两者共用3秒活动预算和同一冻结快照。
- 第二核心是四片几何快图，不是普通UNKNOWN通用FALLBACK，也不读取KNOWN模板。

候选接缝允许：

- 整边与整边连接；
- 整边与部分边连接；
- T 形分段接缝；
- 轮廓反向后的近似重合。

每条关系包含旋转、平移、长度误差、方向误差、接缝距离和局部重叠量。刚体变换只允许旋转和平移，禁止镜像。

搜索策略：

1. 为每个有向片对最多保留约六条最佳关系。
2. 选择约束最强的关系作为起始两片组合。
3. 添加第三片时检查多边形重叠、联合面积和目标尺寸趋势。
4. 添加第四片时生成完整候选并执行精确矩形验收。
5. 中间阶段主要使用解析多边形相交；只有少量完整候选进行栅格精确验收。

四片只有有限的基础连接树，逐层剪枝后无需进行全画布平移和旋转扫描。目标是在 MaixCAM2 上约 `1～3秒` 内完成。

## 11. 矩形验收与目标布局

完整候选必须满足：

- 最终矩形边长以题目范围 `90～120mm × 50～90mm` 为基准，检测验收允许独立
  `±2mm`测量误差；该容差不会缩放目标矩形或改变发送坐标；
- 严格轮最低填充率为 `0.92`；
- 严格轮无解后才启用最低填充率 `0.85` 的宽松轮；
- 总重叠率不超过 `3%`；
- 不存在镜像、退化、自交或遗漏碎片；
- 每片至少与目标外边或另一片形成有效几何关系。

通过验收后，将整个拼成的矩形旋转和平移到下半区可达范围。求解器根据每片冻结时的源重心和最终刚体变换计算：

- 源中心毫米坐标；
- 目标中心毫米坐标；
- 归一化到 `[-180°, 180°)` 的旋转角。

## 12. UART4 输出

四片模式继续使用当前拼图结果帧，不增加模式专用协议。

每片记录仍包含：

```text
源中心 X、源中心 Y、目标中心 X、目标中心 Y、旋转角
```

坐标单位为纸面毫米，角度单位为度，发送时均按现有协议乘以十并编码为定点整数。F4 无需根据普通模式或 FOUR 模式切换解析方式。

一组四片结果在同一协议帧内一次发送完成，并由任务级发送标志防止重复发送。

## 13. 调试画面与日志

FOUR 调试画面支持查看：

- 完整 A4 透视展开图；
- 严格核心掩膜；
- 宽松支撑掩膜；
- 最终恢复掩膜；
- 每片轮廓、编号、重心、面积和边线；
- 当前计数、稳定帧数和是否执行过粘连拆分；
- 最佳候选的填充率、重叠率和矩形尺寸。

`FOUR_SOLVER_DEBUG` 控制电脑端详细日志。关闭后不构造高成本诊断字符串。

## 14. 失败处理

| 状态 | 含义 | 行为 |
|---|---|---|
| `FOUR NO PAPER` | 缺少有效 A4 标定 | 停止，不猜测坐标 |
| `FOUR COUNT n/4` | 轮廓数量不正确 | 显示数量和掩膜，等待稳定或超时 |
| `FOUR UNSTABLE` | 重心或面积变化过大 | 不锁定、不求解 |
| `FOUR NO EDGE` | 缺少可用接缝关系 | 保留边线调试图 |
| `FOUR NO RECT` | 候选未通过矩形硬验收 | 显示最佳候选指标 |
| `FOUR TIMEOUT` | 专用搜索超过预算 | 终止，不进入旧 FALLBACK |
| `FOUR TARGET RANGE` | 结果无法放入可达区域 | 保留结果但不发送错误坐标 |

任何失败都保留最后快照，且必须由用户手动 START/RETRY 才能重新执行。

## 15. 测试与验收

### 15.1 单元测试

- 横放和竖放 A4 的 Homography 与毫米映射；
- HSV/LAB 双阈值和区域恢复；
- 小噪点过滤、孔洞填充和受限粘连拆分；
- 跨帧轮廓匹配与稳定锁定；
- 重心、边线、角点和形状假设提取。

### 15.2 求解测试

- 四片任意源位置和任意旋转；
- 整边、部分边和 T 形分段接缝；
- 严格和宽松填充率；
- 重叠、镜像、尺寸越界和超时拒绝；
- 目标布局及每片旋转角验证。

### 15.3 回归与协议测试

- 当前全部测试继续通过；
- KNOWN 和 UNKNOWN 一至三片不导入、不调用四片视觉和求解入口；
- 四片结果帧编解码往返一致；
- 一次任务只发送一次结果；
- 串口解码值与屏幕显示一致。

### 15.4 实机验收

- 横放、竖放和倾斜相机条件下均能正确展开 A4；
- 白纸覆盖不完整、轻微阴影和局部反光下仍能得到稳定四轮廓；
- 两片间距大于约 `2mm` 时不应被形态学操作主动连接；
- 四片稳定后通常在 `1～3秒` 内完成；
- 源中心与现有毫米映射通常相差不超过 `2mm`；
- 目标中心和旋转角与屏幕规划一致。
